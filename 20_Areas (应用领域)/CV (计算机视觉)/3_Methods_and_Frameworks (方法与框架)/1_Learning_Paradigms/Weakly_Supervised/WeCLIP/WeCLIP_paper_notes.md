# Frozen CLIP: 弱监督语义分割的强大骨干网络

# 摘要

弱监督语义分割凭借图像级标签取得了巨大成就。最近的几种方法使用 CLIP 模型生成伪标签来训练单独的分割模型，但尚未尝试将 CLIP 模型作为骨干网络直接使用图像级标签进行对象分割。在本文中，我们提出了 WeCLIP，一个基于 CLIP 的单阶段流水线，用于弱监督语义分割。具体而言，冻结的 CLIP 模型被用作语义特征提取的骨干网络，并且设计了一个新的解码器来解释提取的语义特征以进行最终预测。同时，我们利用上述冻结骨干网络生成伪标签来训练解码器。这些标签在训练过程中无法优化。然后，我们提出了一个细化模块（RFM）来动态纠正它们。我们的架构强制所提出的解码器和 RFM 相互受益，从而提升最终性能。大量实验表明，我们的方法显著优于其他方法，且训练成本更低。此外，我们的 WeCLIP 在全监督设置下也取得了可喜的成果。代码已开源。

# 1. 引言

弱监督语义分割（WSSS）[2, 48, 56] 旨在从弱监督中学习像素级分割模型，从而减少手动标注的工作量。常见的弱监督信号包括涂鸦 [27]、边界框 [43]、点 [4] 和图像级标签 [1, 19, 47, 52]。在这些监督方式中，图像级标注是最流行的一种，因为这些标注可以通过网络爬取轻松获得。

对于使用图像级标签的 WSSS，有两种训练方案：多阶段训练和单阶段训练。对于现有的单阶段方法，它们的骨干网络依赖于在 ImageNet [11] 上的预训练，并在训练期间进行微调，如图 1(a) 所示。这种单阶段训练 [3, 55] 侧重于使用一个模型直接分割带有弱信号作为监督的对象。以前的单阶段架构主要考虑在线细化类激活图（CAM）[39] 或改进分割分支 [57, 61]。由于架构复杂，单阶段方法的性能通常不如多阶段方法。

![](../../../../../../99_Assets%20(资源文件)/images/55597c797630107247b87f48aea84a40.png)

图 1. 我们的方法与其他单阶段或基于 CLIP 的方法的比较。(a) 以前的单阶段方法，使用可训练的 ImageNet [11] 预训练骨干网络，具有可训练的分类和分割过程。(b) 以前的基于 CLIP 的方法，这是一种多阶段方法，使用冻结的 CLIP 模型生成伪标签并训练一个单独的 ImageNet 预训练分割模型。(c) 我们的方法。我们的方法是一种单阶段方法，使用冻结的 CLIP 模型作为骨干网络，具有可训练的分割过程，显著降低了训练成本。

另一方面，多阶段训练尝试利用几个单独的模型来形成一个训练流水线 [23, 26, 47]，其中首先使用 CAM [63] 从弱标签生成离线像素级伪标签，然后使用这些伪标签训练分割模型。由于 CAM 只能突出区分性区域，许多以前的方法专注于提高 CAM 的质量 [14, 49, 54, 59] 以获得更好的伪标签。此外，一些最近的多阶段方法 [25, 29, 51] 尝试引入对比语言-图像预训练（CLIP）[36] 用于 WSSS。CLIP 在 4 亿图像-文本对上进行训练，建立了图像和文本之间的强大关系，展示了定位对象的出色能力 [18, 20, 51, 60, 65]。在此基础上，现有方法 [29, 51] 使用 CLIP 来改进 CAM，提供了令人惊讶的高质量伪标签。它们遵循图 1(b) 中的流水线。然而，这些方法仅使用 CLIP 模型来改进 CAM 以获得更好的伪标签。CLIP 模型作为骨干网络直接用于提取强大语义特征以进行分割预测的潜力尚未被探索。

在本文中，我们提出了一种基于 CLIP 的单阶段流水线用于弱监督语义分割（WeCLIP），其中 CLIP 模型可以直接用于分割预测，如图 1(c) 所示。具体而言，我们采用冻结的 CLIP 模型作为骨干网络，后面跟着一个新设计的轻量级冻结 CLIP 特征解码器，其中 CLIP 骨干网络不需要任何训练或微调。我们的解码器可以成功解释冻结的 CLIP 特征，以少量可学习参数执行分割任务。

我们利用冻结的 CLIP 骨干网络生成 CAM 以提供像素级伪标签来训练我们的解码器。然而，冻结的骨干网络只能提供静态 CAM，这意味着用作监督的伪标签在训练期间无法改进。伪标签中相同的错误会导致优化在错误方向上无法纠正。因此，我们提出了一个冻结 CLIP CAM 细化模块（RFM）来动态纠正静态 CAM。特别是，我们的 RFM 利用来自解码器的动态特征和来自冻结 CLIP 骨干网络的前置特征来建立高质量的成对特征关系，以修正初始 CAM，从而生成更高质量的伪标签。通过这种设计，我们提出的两个模块相互受益：细化后的伪标签为训练解码器提供了更准确的监督，训练后的解码器为 RFM 建立了更可靠的特征关系，以生成准确的伪标签。

大量实验表明，我们的方法在 PASCAL VOC 2012 和 MS COCO 数据集上均取得了新的最先进性能，并以大幅优势显著优于其他方法。此外，我们的方法在全监督语义分割方面也取得了令人满意的性能。更重要的是，由于 WeCLIP 具有冻结的骨干网络，它只需要少量训练成本，即 6.2GB GPU 内存和少于 6M 可学习参数，远低于其他弱监督或全监督方法。

我们的贡献总结如下：
• 我们发现 CLIP 骨干网络可以直接用于弱监督语义分割而无需微调。通过我们设计的解码器，冻结的 CLIP 特征被直接解释为语义信息以分割对象，构建了一个强大的单阶段解决方案。
• 为了克服冻结骨干网络只提供静态伪标签的缺点，我们设计了一个冻结 CLIP CAM 细化模块（RFM）来动态更新初始 CAM，以为我们的模型提供更好的伪标签。
• 凭借更低的训练成本，我们的方法显著优于以往方法，在弱监督语义分割方面达到了新的最先进性能（VOC 2012 测试集 mIoU：77.2%，COCO 验证集 mIoU：47.1%）。此外，我们的方法在全监督语义分割方面也显示出巨大的潜力。

# 2. 相关工作

## 2.1. 弱监督语义分割

使用图像级监督的弱监督语义分割 [1, 8, 51, 55] 由于人工工作量较少，比其他弱监督 [27, 43] 吸引了更多关注。主要有两种解决方案：多阶段方法 [2, 19, 23, 25, 56] 和单阶段方法 [39, 55]。

多阶段解决方案的关键是生成高质量的伪标签。例如，RIB [23] 在分类网络中设计了边际损失，以减少信息瓶颈，从图像级监督中产生更好的像素级响应。Du 等人 [14] 提出了一种像素到原型对比策略，以强制特征语义一致性以生成更高质量的伪标签。MCTformer [52] 在 Transformer 架构中设计了多类别令牌，以生成类特定注意力响应以生成细化 CAM。一些最近的多阶段方法尝试引入 CLIP 用于此任务。CLIMS [51] 利用 CLIP 模型激活更完整的对象区域并抑制高度相关的背景区域。CLIP-ES [29] 提出使用 CLIP 中的 Softmax 函数计算 GradCAM [41]。通过精心设计的文本提示，CLIP 的 GradCAM 提供了可靠的伪标签来训练分割模型。

以前的单阶段解决方案采用 ImageNet [11] 预训练模型作为骨干网络，同时学习分类和分割任务，其中大多数都专注于通过提供更准确的监督或约束其学习来改进分割。例如，RRM [55] 提出选择可靠的像素作为分割分支的监督。1Stage [3] 设计了一个局部一致性细化模块，直接从图像级标签生成语义掩码。AA&AR [61] 提出了一种自适应亲和力损失，以增强分割分支中的语义传播。AFA [39] 设计了一个亲和力分支来细化 CAM 以生成更好的在线伪标签。ToCo [40] 提出了令牌对比学习，以减轻在线 CAM 生成中的过度平滑问题，从而为分割提供更好的监督。

CLIP 模型在多阶段解决方案中显示出巨大的有效性，但将其用作单阶段解决方案，即直接学习使用图像级监督分割对象尚未被探索。

## 2.2. 全监督语义分割

全监督语义分割旨在使用像素级标签作为监督来分割对象。大多数以前的方法都基于全卷积网络（FCN）[31] 架构，例如 DeepLab [6]、PSPNet [62] 和 UperNet [50]。最近的方法引入了视觉 Transformer [12] 作为骨干网络，通过建立全局关系来提高性能。例如，PVT [46] 使用金字塔视觉 Transformer 进行语义分割。Swin [30] 在视觉 Transformer 中设计了一种基于窗口的注意力机制，以有效提高注意力计算。它们添加了一个 UperNet 头 [50] 进行语义分割。MaskFormer [9] 和 Mask2Former [10] 提出了通过结合 Transformer 解码器和像素解码器来实现通用图像分割架构。无论是全监督还是弱监督语义分割，几乎所有分割模型都依赖于 ImageNet [11] 预训练模型，并且所有模型参数都需要训练或微调，这需要大量的计算成本，而我们使用冻结的 CLIP 模型作为骨干网络，从而大大减少了计算资源。

# 3. 方法

## 3.1. 概述

![](../../../../../../99_Assets%20(资源文件)/images/e2421ff12f0a762e0d89fe613dd71b63.png)

图 2. 我们的 WeCLIP 框架。输入图像被送入冻结的 CLIP 图像编码器以生成图像特征，类别标签用于构建文本提示，然后输入冻结的 CLIP 文本编码器以生成文本特征。分类分数是根据池化后的图像特征和文本特征之间的距离生成的。使用 GradCAM，我们可以生成初始 CAM $M_{init}$。然后，来自每个 Transformer 块最后一层的冻结图像特征被输入到我们的解码器以生成最终的语义分割预测。同时，来自我们解码器的亲和力图 $A_f$ 和来自 CLIP 每个块的多头注意力图 $A_s$ 被输入到我们的 RFM 以建立细化图 $R$ 来细化 $M_{init}$ 为 $M_f$。经过后处理后，它将用作监督来训练我们的解码器。


图 2 展示了我们方法的完整框架，包括四个主要模块：一个冻结的 CLIP 骨干网络（图像编码器和文本编码器）用于编码图像和文本，一个分类过程用于生成初始 CAM，一个解码器用于生成分割预测，一个 RFM 用于细化初始 CAM 以提供伪标签以进行训练。

训练流水线分为以下步骤：
1. 首先，图像被输入到 CLIP 图像编码器以获取图像特征。此外，前景和背景类标签用于构建文本提示，然后输入到 CLIP 文本编码器以生成相应的文本特征。请注意，图像编码器和文本编码器在训练期间都是冻结的。
2. 然后，通过计算图像特征（经过池化后）和文本特征之间的距离生成分类分数。基于分类分数，使用 GradCAM [41] 生成初始 CAM。
3. 此外，来自冻结 CLIP 图像编码器中每个 Transformer 块最后一层的图像特征被输入到我们提出的解码器以进行最终分割预测。
4. 同时，来自我们解码器的中间特征图用于生成亲和力图。然后，亲和力图与来自冻结 CLIP 图像编码器每个块的多头注意力图一起输入到我们提出的 RFM 中。
5. 最后，RFM 输出一个细化图来细化初始 CAM。经过后处理后，从细化 CAM 转换而来的最终伪标签用于监督训练。

### 一、 CLIP 的原始设计与核心原理

你记忆中关于“对比学习”的概念是**完全准确**的！

**1. CLIP 是干什么用的？**
CLIP（Contrastive Language-Image Pre-training）是 OpenAI 提出来的一个强大的多模态预训练模型。它的**核心目的**是：**把图像和文本映射到一个统一的特征空间中**，让相关的图像和文本在这个空间里的距离更近。

**2. 它是怎么对比学习的？**
它在训练时，每次抓取大量（比如 32768 对）“图片-文本描述”对。
*   把图片送入**图像编码器**（Image Encoder，如 ViT），得到图像的特征向量。
*   把文本送入**文本编码器**（Text Encoder），得到文本的特征向量。
*   **对比目标**：让属于同一对的“图像向量”和“文本向量”的余弦相似度最高（正样本），让不是一对的相似度最低（负样本）。

**3. 输入标签得图片？输入图片得标签？**
*   **输入图片得标签（完全可以 - 这叫零样本分类 Zero-shot Classification）：** 给定一张狗的图片，CLIP 提取它的向量。然后你提供几个候选标签（如“猫”、“狗”、“车”），套入模板变成文本（“一张猫的照片”、“一张狗的照片”），提取出三个文本向量。比较图像向量和这三个文本向量的相似度，相似度最高的就是分类结果。**WeCLIP 论文里的“Classification Process”用的就是这个原理！**
*   **输入标签得图片（不能直接生成，但可以检索/指导生成）：** CLIP 本身是**判别式模型**，不是生成式模型（不能像 Midjourney 或 Stable Diffusion 那样直接“画”出图来）。但是，你可以用一个标签去庞大的图库里检索出最相似的图片；或者用 CLIP 作为“裁判”，去指导其他生成模型画画。
### 二、 普通 CAM 与 GradCAM 的区别

WeCLIP 的第一步是要获取一个初始的“激活图”（Initial CAM），这是基于分类结果做出的。

**1. 什么是 CAM (Class Activation Mapping, 类别激活图)？**
CAM 的目的是解释神经网络：**当网络判断这图里有一只“鸟”时，它到底是看了图的哪个区域才做出的决定？**
*   **普通 CAM 的局限性：** 普通 CAM 要求你的神经网络在最后一步必须是 `卷积层 -> 全局平均池化层 (GAP) -> 全连接层 -> 输出`。它是通过提取最后一层卷积的特征图，直接用全连接层的权重进行加权求和得到的热力图。**如果你的网络结构不长这样，就用不了 CAM。**

**2. 什么是 GradCAM (Gradient-weighted CAM)？**
GradCAM 是 CAM 的进化版（泛化版）。
*   **区别与优势：** 它**不需要**修改网络结构，不需要 GAP 层。它是通过**计算梯度（Gradient）** 来实现的。
*   **原理：** 当网络输出“鸟”的概率后，模型对“鸟”这个类别的得分进行反向传播（求导），看看哪几张特征图对“鸟”的得分贡献最大（即梯度最大的区域）。然后用这些梯度作为权重，把特征图加权叠加起来，就能画出一张热力图。热力图越红的地方，说明这个区域对分类为“鸟”越重要。

普通的 CAM 要求 CNN 必须是 `卷积 -> 全局池化 (GAP) -> 全连接` 的特定结构，这导致很多经典网络（比如没有 GAP 层的 VGG 网络）用不了。GradCAM 通过对类别得分进行反向传播，求取最后一个卷积层特征图的**梯度**（代表特征图对该类别的影响力斜率），完美摆脱了网络结构的限制。

**在 WeCLIP 中为什么用 GradCAM？**
在 WeCLIP 里，因为 CLIP 是 Transformer 架构（ViT），完全没有卷积和全连接，所以只能用 GradCAM 这种看“梯度贡献”的方法来找初始高亮区域。CLIP 的骨干网络（如 ViT）没有传统 CAM 需要的结构，且它是一个冻结（Frozen）的模型。所以作者利用目标类别的分类得分，向回求导，用 GradCAM 得到了一张初步的热力图（$M_{init}$），也就是图上的那只鹦鹉大概的轮廓。

### 三、 CLIP 的 Text Encoder 究竟是什么？
其实论文里很少提，因为它很普通：**它是一个标准的 Transformer 文本解码器（Decoder-only），架构类似小型的 GPT-2。**
*   它通常包含 12 个 Transformer 层，特征维度是 512，8 个注意力头。
*   它使用 BPE（Byte Pair Encoding）对文本进行分词。
*   句子末尾会加上一个 `<EOS>`（End of Sequence）特殊的 Token。文本编码器就取这个 `<EOS>` 所在位置输出的向量，作为整个句子的全局特征向量。
### 四、 详细解读 WeCLIP 的架构与流程

这篇论文在做一件极其巧妙的事：**用只有分类能力的 CLIP（且完全冻结不让它更新），加上轻量级的解码器，来完成像素级别的语义分割（把物体的精确边缘抠出来）。** 结合论文给出的图2（图的右下角是最终生成的伪标签和预测），我们将分为四个关键步骤来解析：
#### 1. 冻结的 CLIP 与 初始 CAM (生成 $M_{init}$)
*   **输入：** 图片（鸟）输入 CLIP 的图像编码器。标签（背景、树、天空，以及前景“鸟”）经过提示工程组合成句子，输入文本编码器。
*   **计算：** 计算文本特征和图像特征的距离，得到一个分类得分。
*   **GradCAM：** 对分类得分使用 GradCAM 向回求导，拿到了一张初始的响应图 $M_{init}$（见流程图中间上方那个有些模糊的热力图）。
*   **痛点：** 因为 CLIP 是冻结的，所以这个 $M_{init}$ 比较粗糙，且在整个训练过程中无法改进，如果用它直接当监督信号，模型就学废了。
#### 2. 解码器 (Decoder，图蓝色框区域)
*   **目的：** 把 CLIP 每一层提取到的“深层语义信息”，转换成分割预测结果。
*   **过程：** 提取 CLIP 图像编码器每个 Transformer 块（TB-1 到 TB-N）的中间特征（图中的灰色方块）。经过 MLP（多层感知机）映射后拼在一起，再通过卷积和轻量级的 Transformer 块，最终输出**分割预测图（Pred）**。
*   **副产品（关键）：** 解码器在中间层产生了一个**亲和力图 $A_f$（Affinity map）**。你可以把它理解为：解码器自己判断出来的 **“图像中哪些像素是属于同一类/同一块区域的”**（如果像素i和像素j属于同一个东西，比如都是鸟的羽毛，它们的值就接近）。
#### 3. 核心创新：冻结 CLIP CAM 细化模块 (RFM，图粉色框区域)
这部分是为了解决刚才提到的“痛点”——怎么把粗糙的 $M_{init}$ 变精细。
*   CLIP 虽然没法更新，但它每层内部都保留了自带的多头注意力图 $A_s$（这些图其实隐含了很好的物体结构信息，但有些含噪）。
*   **动态过滤：** 作者用解码器自己学习到的 $A_f$ 去当裁判，和 CLIP 自带的那些 $A_s$ 进行对比（做差求绝对值）。如果某个 $A_s$ 和 $A_f$ 很接近（公式6里的 $S_l$ 小于阈值），就保留它（权重给1）；如果不接近，就抛弃它（权重给0）。
*   **细化（Refinement）：** 把保留下来的高质量 $A_s$ 和 $A_f$ 结合起来，生成一个**精细的细化图 $R$**（Refinement map）。
*   最后，用这个极其精细的 $R$ 去乘上之前那个粗糙的 $M_{init}$。奇迹发生了：原本模糊的 CAM 响应图被雕刻成了非常精细的形状 $M_f$（右侧那张边缘清晰的鸟的热力图）。
#### 4. 生成伪标签与闭环训练
*   精细的 $M_f$ 经过后处理，变成了非黑即黄的掩码图——这就是**伪标签（Pseudo Label）**。
*   最后一步，计算 Loss：
    1.  用刚才做好的伪标签，去监督解码器的预测（Pred），算交叉熵损失（$L_{ce}$）。
    2.  用伪标签去监督解码器生成的亲和力图 $A_f$，让裁判 $A_f$ 本身变得越来越准。
### 五、 WeCLIP 架构张量变化详解 & RFM 深度剖析

为了让你直观理解，我们假设输入图像尺寸为 $I \in \mathbb{R}^{3 \times 224 \times 224}$，ViT 的 patch_size 为 16，所以特征图的空间大小为 $h=14, w=14$ （因为 $224/16=14$），也就是有 $14 \times 14 = 196$ 个 token 参与空间运算。类别数 $C=21$（含背景）。

#### 1. Decoder (解码器) 张量流转
*   **输入：** 提取 CLIP ViT 每一层（共 $N$ 层）的特征图 $\{F_{init}^l\}_{l=1}^N$。每个张量形状为 `[768, 14, 14]`（假设用 ViT-B，维度768）。
*   **MLP 处理：** 对每一层独立做 MLP，输出 $\{F_{new}^l\}$，形状保持 `[768, 14, 14]`。
*   **拼接与卷积：** 把 $N$ 个层的特征在通道维度拼接，然后用卷积降维，得到**融合特征 $F_u$**。假设降维到 $d=256$ 维，此时 $F_u \in \mathbb{R}^{256 \times 14 \times 14}$。
*   **预测输出：** $F_u$ 经过解码器的 Transformer 块，再上采样，得到最终预测 $P \in \mathbb{R}^{21 \times 224 \times 224}$。

#### 2. RFM (特征细化模块) 重点解析！
RFM 的目标是：**用解码器自己学到的亲和力图 $A_f$，去挑选并融合 CLIP 自带的注意力图 $A_s$，从而细化初始的粗糙 $M_{init}$。**

**步骤一：生成裁判图 $A_f$**
*   拿上面的融合特征 $F_u \in \mathbb{R}^{256 \times 14 \times 14}$，把空间维度展平，变成 $F_u \in \mathbb{R}^{256 \times 196}$。
*   做矩阵乘法：$F_u^T \times F_u$。也就是 `[196, 256] × [256, 196] = [196, 196]`。
*   再过一个 Sigmoid 函数，得到亲和力图 $A_f \in \mathbb{R}^{196 \times 196}$。
    * 意义：这个 $196 \times 196$ 的矩阵，代表了图像中 196 个 patch **两两之间**的相似度。如果 $A_f(i, j)$ 接近 1，说明解码器认为第 $i$ 块和第 $j$ 块属于同一个物体。

**步骤二：提取 CLIP 自带的注意力图 $\{A_s^l\}$**
*   从冻结的 CLIP 里取出 $N$ 层的多头注意力图（对头求平均）。每个 $A_s^l \in \mathbb{R}^{196 \times 196}$。
    *   *物理意义：* CLIP 模型原本在提取特征时，各个 patch 互相看对方的权重。

**步骤三：裁判评估与过滤 (公式 6 和 7)**
*   对每一层 $l$，计算 $A_f$ 和 $A_s^l$ 的绝对误差和 $S_l$。
    *   即矩阵对应位置相减求绝对值：$S_l = \sum |A_f - A_s^l|$。$S_l$ 越小，说明这层的 CLIP 注意力图和我们解码器当前的认知越一致。
*   算出一个平均阈值。如果某个 $A_s^l$ 的误差 $S_l$ 小于阈值，门控器 $G_l = 1$（保留）；否则 $G_l = 0$（丢弃）。

**步骤四：构建精细关系图 $R$ (公式 8)**
*   把所有保留下来的 ($G_l=1$) 的 CLIP 注意力图 $A_s^l$ 加起来求平均。
*   然后**逐元素乘以**我们解码器的图 $A_f$。
*   得到细化图 $R \in \mathbb{R}^{196 \times 196}$。
    *   *物理意义：* 强强联手！保留了 CLIP 强大的零样本先验关系，又融入了我们解码器通过训练学到的当前特征关系。

**步骤五：更新 CAM (公式 9)**
*   初始 CAM 通过 GradCAM 得到：$M_{init}^c \in \mathbb{R}^{196 \times 1}$ （把 14x14 展平为 196）。
*   将关系矩阵 $R$ 归一化后，乘以 $M_{init}^c$：
    *   $[196, 196] \times [196, 1] = [196, 1]$。
    *   *物理意义：* 利用精细的像素两两关系 $R$，对原本粗糙的 CAM 进行重新扩散分配。比如原本 CAM 只有鸟的肚子是亮的（高响应），但是 $R$ 告诉它“鸟嘴和鸟肚子是高度相关的”，于是响应值顺着矩阵 $R$ 扩散到了鸟嘴上，边缘就变得精细了！
*   最后 reshape 回去变成 `[14, 14]`，再上采样，经过后处理生成伪标签用于计算 Loss。
### 总结 WeCLIP 的绝妙之处
CLIP 原本是为了宏观的“图像-文本分类”设计的，通过 GradCAM 只能勉强指出“鸟在大概这个位置”。
WeCLIP 的作者非常聪明地**白嫖**了 CLIP 内部冻结的注意力层隐含的边缘信息（$A_s$），通过一个轻量级的小解码器（边学边进化）提供标准（$A_f$），去伪存真，提取出精确的物体轮廓信息。最后用提取出的轮廓作为伪标签（Pseudo Label），自己教自己做极其精细的语义分割。

## 3.2. 冻结 CLIP 特征解码器
我们使用带有 ViT-B 的冻结 CLIP 编码器作为骨干网络，它在训练期间不进行优化。因此，如何设计一个解码器来解释 CLIP 特征以获取语义特征成为一个核心挑战。我们提出了一个基于 Transformer 架构的轻量级解码器，使用 CLIP 特征作为输入进行语义分割。

具体来说，假设输入图像是 $I \in R^{3 \times H \times W}$，$H$ 和 $W$ 分别表示图像的高度和宽度。经过 CLIP 图像编码器后，我们从编码器中每个 Transformer 块的输出生成初始特征图 $\{F_{init}^l\}_{l=1}^N$，其中 $l$ 表示块的索引。然后，对于每个特征图 $F_{init}^l$，使用一个独立的 MLP 模块生成新的相应特征图 $F_{new}^l$：
$$F_{new}^l = W_{1_{fc}}(ReLU(W_{2_{fc}}(F_{init}^l)))$$
其中 $W_{1_{fc}}$ 和 $W_{2_{fc}}$ 是两个不同的全连接层。$ReLU(\cdot)$ 是 ReLU 激活函数。

之后，所有新的特征图 $\{F_{new}^l\}_{l=1}^N$ 被连接起来，然后通过一个卷积层处理以生成一个融合特征图 $F_u$：
$$F_u = Conv(Concat[F_{new}^1, F_{new}^2, ..., F_{new}^N])$$
其中 $F_u \in R^{d \times h \times w}$，d、h 和 w 分别表示特征图的通道维度、高度和宽度。$Conv(\cdot)$ 是一个卷积层，$Concat[\cdot]$ 是连接操作。

最后，我们设计了几个顺序的多头 Transformer 层来生成最终预测 $P$：
$$P = Conv(\phi(F_u)) \uparrow$$
其中 $P \in R^{C \times H \times W}$，$C$ 是包含背景的类别数。$\phi$ 表示顺序的多头 Transformer 块 [12]，每个块包含一个多头自注意力模块、一个前馈网络和两个归一化层，如图 2 右上角所示。$\uparrow$ 是一个上采样操作，用于使预测图大小与原始图像对齐。

## 3.3. 冻结 CLIP CAM 细化
为了为公式 (3) 中的预测 $P$ 提供监督，我们从冻结骨干网络的初始 CAM 生成像素级伪标签。冻结骨干网络只能提供静态 CAM，这意味着用作监督的伪标签在训练期间无法改进。伪标签中相同的错误会导致优化在错误方向上无法纠正。因此，我们设计了冻结 CLIP CAM 细化模块（RFM）来动态更新 CAM，以提高伪标签的质量。

我们首先遵循 [29] 的方法生成初始 CAM。对于给定图像 $I$ 及其类别标签，$I$ 被输入到 CLIP 图像编码器。类别标签用于构建文本提示并输入到 CLIP 文本编码器。然后，提取的图像特征（经过池化后）和文本特征用于计算距离，并通过 Softmax 函数进一步激活以获得分类分数。之后，我们使用 GradCAM [41] 生成初始 CAM $M_{init} \in R^{(|C_I|+1) \times h \times w}$，其中 $(|C_I|+1)$ 表示图像 $I$ 中包含背景的所有类别标签。更多详细信息可在我们的补充材料或 [29] 中找到。

为了充分利用 CLIP 的先验知识，CLIP 模型是固定的。尽管我们发现这种冻结的骨干网络可以通过仅图像级标签为初始 CAM 提供强大的语义特征，如图 3(a) 所示，$M_{init}$ 无法优化，因为它是由冻结的骨干网络生成的，从而限制了伪标签的质量。因此，如何在训练期间纠正 $M_{init}$ 成为一个关键问题。我们的直觉是使用特征关系来纠正初始 CAM。然而，我们不能直接使用 CLIP 图像编码器中的注意力图作为特征关系，因为这些注意力图也是固定的。然而，解码器在不断优化，我们尝试使用其特征建立特征关系，以指导从 CLIP 图像编码器中选择注意力值，保留有用的先验 CLIP 知识并消除噪声关系。通过更可靠的特征关系，CAM 质量可以动态增强。

![](../../../../../../99_Assets%20(资源文件)/images/533e95e32083c7a6eabe70ccc8c44d29.png)

图 3. 关于 CAM 的定性比较。(a) 初始 CAM。(b) [29] 中提出的通过注意力图细化的 CAM。(c) 我们细化的 CAM。我们的方法产生更准确的响应。

具体来说，我们首先基于我们解码器中公式 (2) 中的特征图 $F_u$ 生成一个亲和力图：
$$A_f = Sigmoid(F_u^T F_u)$$
其中 $F_u \in R^{d \times h \times w}$ 首先被展平为 $R^{d \times hw}$。$Sigmoid(\cdot)$ 是 Sigmoid 函数，以保证输出范围在 0 到 1 之间。$A_f \in R^{hw \times hw}$ 是生成的亲和力图。$T$ 表示矩阵转置。

然后我们从冻结的 CLIP 图像编码器中提取所有多头注意力图，表示为 $\{A_s^l\}_{l=1}^N$，每个 $A_s^l \in R^{hw \times hw}$。对于每个 $A_s^l$，我们使用 $A_f$ 作为标准图来评估其质量：
$$S_l = \sum_{i=1}^{hw} \sum_{j=1}^{hw} |A_f(i,j) - A_s^l(i,j)|$$
我们使用上述 $S_l$ 为每个注意力图计算一个滤波器：
$$G_l = \begin{cases} 1, & \text{if } S_l < \frac{1}{N-N_0+1} \sum_{l=N_0}^N S_l \\ 0, & \text{else} \end{cases}$$
其中 $G_l \in R^{1 \times 1}$，并被扩展为 $G_l^e \in R^{hw \times hw}$ 以进行进一步计算。我们使用所有 $S_l$ 的平均值作为阈值。如果当前的 $S_l$ 小于阈值，则它更可靠，我们将其滤波器值设置为 1。否则，我们将其滤波器值设置为 0。基于此规则，我们保留高质量的注意力图并去除弱注意力图。

然后我们结合 $A_f$ 和上述操作来构建细化图：
$$R = A_f \frac{1}{N_m} \sum_{l=1}^N G_l^e A_s^l$$
其中 $N_m$ 是有效 $A_s^l$ 的数量，即 $N_m = \sum_{l=N_0}^N G_l$。

然后，遵循先前的方法 [29]，我们生成细化后的 CAM：
$$M_f^c = \left( \frac{R_{nor} + R_{nor}^T}{2} \right)^\alpha \cdot M_{init}^c$$
其中 $c$ 是特定类别，$M_f^c$ 是类别 $c$ 的细化 CAM，$R_{nor}$ 是通过行和列归一化（Sinkhorn 归一化 [42]）从 $R$ 获得的。$\alpha$ 是一个超参数。这一部分通过一个框掩码指示器 [29] 来限制细化区域。$M_{init}^c$ 是类别 $c$ 经过重塑为 $R^{hw \times 1}$ 后的 CAM。最后，$M_f$ 被输入到在线后处理模块，即 [39] 中提出的像素自适应细化模块，以生成==最终的在线伪标签 ==$M_p \in R^{h \times w}$。

通过这种方式，我们的 RFM 使用解码器中更新的特征关系来评估冻结骨干网络中的特征关系，以选择可靠的关系。然后，在每张图像的更可靠特征关系的帮助下，可以生成更高质量的 CAM。图 3 展示了使用不同细化方法生成的 CAM 的详细比较。我们的方法比 [29] 中提出的静态细化方法和初始 CAM 产生更准确的响应。

### 一、 核心解惑：为什么要有可训练的 MLP？RFM 需要训练吗？

1. **Decoder 确实是需要训练的（核心发力点）：**
   * **为什么不能直接用 CLIP 特征图？** 
     CLIP 预训练的任务是**全局的图文匹配**（整张图对应一句话），它的特征空间是为了“宏观对比”优化的。而你要做的是**密集的像素级语义分割**。如果直接用它冻结的特征，由于缺乏局部像素级的适应性，根本分不出精细的边界。
   * **MLP 的作用（域对齐与特征映射）：** 
     插入 MLP（$W_{1_{fc}}, W_{2_{fc}}$）的作用，就是为了在“冻结的 CLIP 特征”和“我们要的分割特征”之间，架起一座**可训练的桥梁**。每一层单独加 MLP，相当于给网络充足的可学习参数（自由度），让梯度在反向传播时，能够把死板的 CLIP 知识“翻译”成适合分割的稠密特征（Dense Features）。

2. **RFM 模块本身“没有参数”，但它是“可导的”：**
   * RFM（粉色框）内部所有的操作（做差、求和、比较、相乘）全是**纯数学运算**，它内部没有类似卷积层或全连接层那样需要更新的权重（Weights）。
   * **但是！** RFM 的输入之一是 $A_f$，$A_f$ 是 Decoder 算出来的。所以，算完伪标签并计算 Loss 后，梯度是可以顺着 RFM 流回 $A_f$，进而流回 Decoder 的！RFM 其实是利用 Decoder 的成长，来动态挑选特征的。
### 二、 多头注意力图 $A_s$ 是怎么提取出来的？
由于论文里只是一笔带过，这里为你补齐 ViT 内部的张量细节：
* 输入图片 $224 \times 224$，经过 ViT 变成 $14 \times 14 = 196$ 个 patch。
* 在 CLIP 图像编码器（ViT）的任意一个 Transformer Block 中，其多头注意力矩阵的原始形状是：`[Batch, Heads, 196, 196]`（这里省略了 Class Token，只看空间 patch）。
* 假设头数 `Heads = 12`。怎么变成图里的 $A_s$ 呢？
  网络会将这 12 个头的注意力图**沿着头（Heads）维度求平均**（或者按特定规则融合）。
* **最终得到的 $A_s^l$ 的形状是：`[196, 196]`。** 
  * **物理意义：** 这个二维矩阵里的每一个值 $A_s(i, j)$，代表第 $i$ 个图像块和第 $j$ 个图像块在 CLIP 视角下的“注意力关联度”。图里画的一摞 $A_s$，代表的是从第 1 层到第 $N$ 层提取出的一共 $N$ 个 `[196, 196]` 的矩阵集合。
### 三、 极致硬核：RFM 张量变化与流程详解（解答 Expand 和 两个 $\bigotimes$）

现在我们紧盯粉色框（RFM），按照图示从左到右一步步推导张量变化，解答你的所有疑惑。

**前置条件：**
* $A_f$（来自 Decoder）：形状 `[196, 196]`。
* $A_s$（来自冻结 CLIP 的 $N$ 个层）：集合 $\{A_s^1, A_s^2, ..., A_s^N\}$，每个形状也是 `[196, 196]`。
#### 步骤 1：生成滤波器（判断 CLIP 注意力图哪层好用）
* **Difference（图中的 $\ominus$）：** 
  对每一层 $l$，计算 $A_f$ 和 $A_s^l$ 的绝对值误差矩阵。
  张量：`[196, 196] - [196, 196] -> [196, 196]`
* **Sum（求和）：**
  将上述误差矩阵里的所有元素加起来，得到一个标量值 $S_l$（对应公式 6）。
  张量：`[196, 196] -> 标量 Scalar (1x1)`
* **Compare -> mean（比较并生成门控信号 $G$）：**
  计算所有 $N$ 层 $S_l$ 的平均值作为阈值。如果 $S_l <$ 阈值，输出 1，否则输出 0。
  **此时产生的门控信号 $G_l$ 只是一个标量（Scalar 1或0，如图中的红/白小方块）。**
#### 步骤 2：解惑 Expand 操作（为什么要扩展？）
* **为什么要 Expand？**
  你想把这个门控信号作用回原有的注意力图 $A_s^l$（形状 `[196, 196]`）上。在严格的张量图计算中，标量不能直接和矩阵做哈达玛积（元素级乘法）。
* **Expand 的作用：**
  将标量 $G_l$ (1 或 0) **在空间维度（$H \times W$ 即 $196 \times 196$）上进行复制/广播**。
  张量变化：`[1x1]` $\xrightarrow{expand}$ `[196, 196]`（变成了一个全1矩阵，或者全0矩阵 $G_l^e$）。
#### 步骤 3：解惑两个 $\bigotimes$ (Element-wise Multiplication)
仔细看图右侧部分，**有两次黑色的 $\bigotimes$ 操作，且完全对应公式 (8)**：
$$ R = A_f \cdot \left( \frac{1}{N_m} \sum_{l=1}^N G_l^e \cdot A_s^l \right) $$

* **第一个 $\bigotimes$（过滤噪声层）：**
  * 参与者：扩展后的门控矩阵 $G_l^e$ (`[196, 196]`) 与 原始注意力图 $A_s^l$ (`[196, 196]`)。
  * 运算：对应位置元素相乘（如果是全1矩阵就保留 $A_s^l$，全0矩阵就整层抹除变成 0）。
  * 经过第一重 $\bigotimes$ 和随后的 **mean** 操作，相当于把那些**被判定为高质量的 $A_s^l$ 筛选出来并求了平均**。
  * 此时张量依然是：`[196, 196]`。
* **第二个 $\bigotimes$（最核心的特征融合）：**
  * 参与者：图里有一条线从 Decoder 下方的 $A_f$ (`[196, 196]`) 直接连了过来！它和刚才 mean 出来的优质 CLIP 注意力图 (`[196, 196]`) 碰头了。
  * 运算：这两个矩阵再次进行**逐元素相乘（Element-wise Multiplication）**！
  * **为什么这么干（物理意义）？** $A_f$ 是 Decoder 刚学会的、针对当前图像的像素级判断；筛选出的 $A_s$ 是 CLIP 固有的常识先验。两者相乘，相当于 **“强强联手”**，只有当 Decoder 和 CLIP 先验都认为像素 i 和像素 j 属于同一类时，最终的关系矩阵 $R$ 中该位置的值才会高。
  * 输出：最终的细化关系图 $R$ (`[196, 196]`)。
#### 步骤 4：生成最终的细化图 $M_f$
拿到了极其精确的像素关系图 $R$ `[196, 196]`，结合左侧传过来的粗糙 $M_{init}$ (经过 flatten 变为 `[196, 1]`)，进行矩阵乘法（对应公式 9）。
这一步就是利用 $R$ 矩阵中精确的边缘关系，把 $M_{init}$ 模糊的激活值“传导”到精确的物体边缘内，最后 Reshape 并上采样，就得到了极度清晰的 $M_f$。

## 3.4. 损失函数
在我们的 RFM 中，我们使用亲和力图 $A_f$ 来选择注意力图并构建最终的细化图。因此，$A_f$ 的有效性直接决定了在线伪标签的质量。考虑到 $A_f$ 是使用我们解码器中的特征图 $F_u$ 生成的，并且是一个可学习的模块，我们提出了一个学习过程用于 $A_f$，该过程使用从 $M_p$ 转换而来的在线伪标签作为监督。

具体来说，$M_p$ 首先被转换为每对像素的像素级亲和力标签：
$$\hat{A} = O_h(M_p)^T O_h(M_p)$$
其中 $O_h(\cdot)$ 是一热编码，$O_h(M_p) \in R^{C \times hw}$，$\hat{A} \in R^{hw \times hw}$ 是亲和力标签。$\hat{A}(i,j) = 1$ 表示像素 $i$ 和 $j$ 具有相同的标签，否则 $\hat{A}(i,j) = 0$。

基于上述标签 $\hat{A}$ 和在线标签 $M_p$，我们的 WeCLIP 的完整损失函数为：
$$L = L_{ce}(P, M_p \uparrow) + \lambda L_{re}(A_f, \hat{A})$$
其中 $L_{ce}$ 是交叉熵损失，$M_p \uparrow \in R^{H \times W}$，$\lambda$ 是权重参数。$P$ 是公式 (3) 中的预测。通过公式 (10)，建立了更准确的特征关系以获得更高质量的伪标签。反过来，通过更好的伪标签，建立了更精确的特征关系。因此，我们的解码器和 RFM 可以相互受益，以促进训练。
***
### 一、 核心解惑：为什么能“左脚踩右脚”？相互受益的逻辑）

首先回答你觉得奇怪的地方。为什么 $M_p$ 有资格当老师去监督 $A_f$？
因为 $M_p$ **不仅仅**是 $A_f$ 算出来的。回想上一问：$M_p$ 是由 **Decoder 的 $A_f$** + **CLIP冻结的 $A_s$** + **CLIP的粗糙 $M_{init}$** 三者强强联手融合出来的。
* $A_f$ 就像个正在学习的学生，知识还不完善。
* 但是融合后的 $M_p$ 吸收了 CLIP 庞大且固定的先验知识（比如真实的鸟长啥样），所以 $M_p$ 比当前的 $A_f$ **更聪明、更准确**。
* 因此，把 $M_p$ 转化为标签 $\hat{A}$ 后，它完全有资格回头去纠正 $A_f$ 的错误。当 $A_f$ 变强了，下一轮生成的 $M_p$ 也会更精细。这就是论文最后一句话“**相互受益以促进训练**”的真谛。
### 二、 极度硬核：公式 (10) 张量手术（伪标签怎么变成亲和力标签的？）

这部分是纯粹且极其优美的线性代数操作。我们来看看 $M_p$ 是怎么变成 $\hat{A}$ 的。
**前置条件：**
假设图像特征图大小为 $h=14, w=14$，总像素点 $N = 14 \times 14 = 196$。类别数 $C=21$。

1. **什么是 $M_p$？**
   $M_p$ 是一张二维的分割结果图，形状是 `[14, 14]`，里面存的是具体的类别 ID（比如 0 代表背景，1 代表鸟）。展平后，它是一个长度为 196 的向量，即 $M_p \in \mathbb{R}^{196}$。

2. **什么是 $O_h(M_p)$（One-hot 编码）？**
   把这 196 个类别 ID 变成 One-hot（独热）向量。
   * 张量变化：`[196]` $\xrightarrow{One-hot}$ `[C, 196]`（即 `[21, 196]`）。
   * 物理意义：每一列代表一个像素。如果第 $i$ 个像素是“鸟（ID=1）”，那这一列的第 1 行是 1，其他 20 行全是 0。

3. **魔法时刻：$O_h(M_p)^T \times O_h(M_p)$（矩阵乘法）**
   * 公式：$\hat{A} = O_h(M_p)^T \times O_h(M_p)$
   * 维度运算：`[196, 21]` $\times$ `[21, 196]` = `[196, 196]`。
   * **到底算出了个啥？（重点！）**
     根据矩阵乘法规则，结果矩阵 $\hat{A}$ 的第 $(i, j)$ 个元素，其实就是 **左边矩阵的第 $i$ 行** 与 **右边矩阵的第 $j$ 列** 的点乘（Dot Product）。
     而这两个向量都是 One-hot 向量。**两个 One-hot 向量点乘，只有当它们一模一样（即属于同一个类别）时，结果才是 1；只要类别不同，结果绝对是 0。**
   * **结论：** 经过这个极其简单的矩阵乘法，我们完美得到了一张 `[196, 196]` 的二值化亲和力标签矩阵 $\hat{A}$。
     * 如果 $\hat{A}(i, j) = 1$：说明伪标签认为第 $i$ 个像素和第 $j$ 个像素是同类（比如都是鸟）。
     * 如果 $\hat{A}(i, j) = 0$：说明它们不是同类（比如一个是鸟，一个是背景）。
### 三、 深度剖析：完整损失函数 公式 (11)

我们现在有了两个东西：一个是最终的分割图 $P$，一个是 Decoder 中间算出来的亲和力图 $A_f$。
同时我们也有了两个老师（标签）：伪标签 $M_p$ 和 亲和力标签 $\hat{A}$。

损失函数：$L = L_{ce}(P, M_p \uparrow) + \lambda L_{re}(A_f, \hat{A})$

#### 1. 第一部分：常规分割损失 $L_{ce}(P, M_p \uparrow)$
* **参与者：** 
  * $P$：Decoder 最末端输出的预测图，形状 `[21, 224, 224]`（已通过 Softmax，是概率分布）。
  * $M_p \uparrow$：生成的伪标签 $M_p$ `[14, 14]`，通过插值上采样（$\uparrow$）放大到 `[224, 224]`。
* **计算啥：** 交叉熵损失（Cross Entropy）。
* **物理意义：** 这就是最经典的图像分割 Loss。拿生成的（虽然是伪造的）目标区域当真实标签，强迫 Decoder 的输出 $P$ 在像素级别去逼近这个形状。梯度会流经整个 Decoder（包括那些 Transformer 层和 MLP）。

#### 2. 第二部分：特征对齐/正则化损失 $L_{re}(A_f, \hat{A})$
* **参与者：**
  * $A_f$：Decoder 在中间特征 $F_u$ 时算出来的亲和力图，形状 `[196, 196]`，里面的值是 $0 \sim 1$ 的连续浮点数（通过 Sigmoid 算出来的）。
  * $\hat{A}$：刚刚通过公式 10 算出来的，绝对的 0 或 1 的标签，形状也是 `[196, 196]`。
* **计算啥：** 虽然论文没明说 $L_{re}$ 具体是啥（通常是 L1 Loss、MSE 或者二元交叉熵 BCE），但作用是算两者的差距。
* **物理意义（核心点）：** 我们要逼迫 Decoder 内部的特征 $F_u$ 产生 **“类内聚集，类间排斥”** 的效果。
  * 如果伪标签说 $i$ 和 $j$ 是同类（$\hat{A}(i,j)=1$），Loss 就会惩罚 $A_f(i,j)$ 偏离 1 的部分。这就逼迫 Decoder 在 MLP 和前面的层中，把第 $i$ 个像素和第 $j$ 个像素的特征向量拉近。
  * 反之，逼迫它们特征推远。
  * 这部分梯度直接打在 Decoder 中间的特征层上，使得 Decoder 学习到的特征极具判别力。

### 总结
你之所以觉得奇怪，是因为你敏锐地察觉到了**数据流的环路**。
传统深度学习是：`输入 -> 网络 -> 输出 -> (对比真实标签) -> 计算 Loss -> 更新网络`。单向到底。
WeCLIP 的玩法是：`输入 -> 冻结模型 + 可学习网络 -> 吐出粗糙特征 -> 自己做一波数学融合（RFM）变成精细伪标签 -> (把精细伪标签当真实标签) -> 计算 Loss -> 更新可学习网络`。

公式 10 是一手极漂亮的矩阵魔术，公式 11 则是双管齐下（既管最终结果 $P$，又管中间特征 $A_f$），彻底盘活了整个网络的自我进化过程！

# 4. 实验

## 4.1. 数据集
遵循大多数先前弱监督语义分割方法 [14, 19, 23] 的设置，使用两个数据集评估我们的方法：PASCAL VOC 2012 [15] 和 MS COCO-2014 [28]。PASCAL VOC 2012 通过 SBD [17] 扩展数据集，整个数据集包含 10,582 张训练图像、1,446 张验证图像和 1,456 张测试图像，共 20 个前景类别。MS COCO-2014 数据集包含大约 82,000 张训练图像和 40,504 张验证图像，共 80 个前景类别。

平均交并比（mIoU）用作评估标准。

## 4.2. 实施细节
我们使用带有 ViT-16-base 架构 [13] 的冻结 CLIP 骨干网络，$N$ 是一个固定数字，等于 12。对于 PASCAL VOC 2012 数据集上的训练，批大小设置为 4，最大迭代次数设置为 30,000。对于 MS COCO-2014 数据集上的训练，我们设置批大小为 8，最大迭代次数为 80,000。

所有其他设置在训练期间对两个数据集采用相同的参数：我们使用 AdamW [32] 作为优化器，学习率为 $2e^{-3}$，权重衰减为 $1e^{-3}$，所有图像在训练期间都被裁剪为 $320 \times 320$。公式 (10) 中的 $\lambda$ 设置为 0.1。我们解码器中 MLP 模块（公式 (1)）的维度设置为 256。在公式 (3) 的 $\phi$ 中，三个 Transformer 编码器（多头数为 8）层级联以生成最终特征图，每个层的输出维度为 256。公式 (6) 中的 $N_0$ 设置为 6。公式 (8) 中的 $\alpha$ 按照 [29] 设置为 2。

在推理过程中，我们使用多尺度 `{0.75, 1.0}`。遵循先前的方法 [39, 40, 53]，DenseCRF [21] 用作后处理方法来细化预测。

# 5. 结论
我们提出了 WeCLIP，一个基于冻结 CLIP 骨干网络的单阶段流水线，用于弱监督语义分割。为了解释冻结特征以进行语义预测，我们设计了一个基于 Transformer 架构的冻结 CLIP 特征解码器。同时，我们提出了一个冻结 CLIP CAM 细化模块，它使用来自我们解码器的可学习特征关系来细化 CAM，从而明显提高了伪标签的质量。我们的方法以更低的训练成本取得了更好的性能，显示出解决该任务的巨大优势。我们还评估了我们的方法在全监督语义分割方面的有效性。我们的解决方案提供了一个不同于传统方法的视角，即骨干网络的训练是不必要的。我们相信所提出的方法可以在这个方向上进一步推动研究。
