# Leveraging Class Distributions in CLIP for Weakly Supervised Semantic Segmentation

# 利用 CLIP 中的类别分布进行弱监督语义分割

## 摘要

图像级弱监督语义分割（WSSS）通常利用类激活图（CAM）进行像素级定位。然而，现有基于 CLIP 的方法往往生成激活不足的 CAM，主要原因是基于亲和力的细化过程中语义关系不准确。在这项工作中，我们提出了一种新框架 CD-CLIP（Class Distribution based CLIP，基于类别分布的 CLIP），通过引入类别分布感知（Class Distribution Aware，CDA）模块来解决这一问题。CDA 模块使用 Jensen–Shannon 散度，对各图像块在所有类别上的分布进行建模，捕获更丰富的语义关系，从而增强 CAM 的完整性。虽然这显著改善了前景类别的覆盖范围，但由于全面整合了不同目标类别之间的关系，类别边界处也可能出现过度激活。为了减轻这种现象对分割监督的不利影响，我们引入超类边界探索（Super-class Boundary Exploration，SBE）模块，利用 DINO 的结构知识生成具有边界感知能力的超类原型 CAM。通过使用边界增强损失，我们的 SBE 模块有效地为最终分割提供准确的边界监督。所提出的 CD-CLIP 框架在 PASCAL VOC 和 MS COCO 两个基准上均取得了最先进的性能。代码可在[此处](https://github.com/yay97/CD-CLIP)获取。

## 1. 引言

近年来，弱监督语义分割（WSSS）被提出，用于仅凭弱标注生成像素级预测。与依赖像素级标注的全监督语义分割相比，它有效降低了高昂的标注成本与人力消耗。弱标注包括点 [3]、涂鸦 [26, 41]、边界框 [9, 23] 和图像级标签 [1, 31, 52]。本文关注应用广泛但具有挑战性的图像级标签。

在图像级 WSSS 中，以定位能力著称的类激活图（CAM）被广泛用于生成伪标签，进而为分割解码器提供密集监督。近期研究探索了利用在 4 亿个图像–文本对上预训练的对比语言–图像预训练模型（Contrastive Language-Image Pre-training，CLIP）来生成 CAM。然而，由于从图像级标签中获得的语义信息有限，CLIP 在没有专门训练过程的情况下生成的初始 CAM 通常较为粗糙，并且主要只激活最具辨识度的区域，从而影响 WSSS 的性能。

为了解决这一局限，现有基于 CLIP 的方法通常采用视觉 Transformer（ViT）编码器中的多头自注意力（MHSA）权重，对图像块间的语义亲和力进行建模；在这种建模中，空间上相邻且语义相似的图像块被赋予较强的关系。尽管这种基于亲和力的细化能够扩大 CAM 的激活区域，我们仍发现了一个关键缺陷：如图 1(a) 所示，所得到的亲和力往往无法建立准确的类内语义关系，导致目标类别激活不足（例如，“人”类别中的“头部”仍未被激活）。此外，图 1(b) 中的类别分布分析揭示了一个有趣现象：虽然这些选定的前景图像块对目标类别表现出不同响应（例如，黑框图像块的“人”得分较高，而红框图像块的得分较低），但它们在某些不相关类别上的类别分布却高度相似。这一发现表明，丰富的类别分布所包含的语义信息比仅有目标类别的激活更有价值。通过利用所有类别上的这种分布知识，我们可以实现更精确、更全面的 CAM 细化，有效解决当前基于亲和力的方法中的激活不足问题。

![](../../../../../../99_Assets%20(资源文件)/images/CD-CLIP_Figure_1.png)

**图 1. 我们的动机。** (a) CLIP 中由 MHSA 亲和力细化后的所有类别的 CAM。同一目标类别中选取的图像块分别用“红框”和“黑框”标记。MHSA 亲和力未能在这两个选定图像块之间建立正确的关系。(b) 两个选定图像块的类别分布。我们测量两个图像块的类别分布之间的 Jensen–Shannon（JS）散度。结果表明，同一目标类别中的图像块表现出高度相似的类别分布，这促使我们通过这些分布来识别正确的关系。

**图片内容解释：** (a) 展示同一图像在飞机、自行车、鸟、船、瓶子、摩托车、人和盆栽等类别上的 CAM，并在人物区域标出两个图像块。(b) 分别展示这两个图像块在 20 个类别上的得分分布，并用 JS 散度比较它们的相似性。

> [!note] 我的理解｜目标类得分低，不等于这个 patch 没有语义信息
> 传统 CAM 首先问“这个位置有多像 person”，再把高响应位置的分数沿亲和关系传播。问题是同一个人的躯干、头部、衣服可能有很不一样的 person 响应：只比较这个类别上的一个分数，会把原本属于同一物体的区域看成不相似。
>
> CD-CLIP 换了一个观察角度：把每个 patch 对所有类别的响应排成一串，比较两串响应的整体形状。即使两个 patch 的 person 得分不同，它们对 bird、boat、bicycle 等类别的相对响应仍可能很接近。这些“非目标类分数”在这里不是要被当成最终标签，而是作为识别 patch 语义关系的额外线索。可以把它理解成“语义响应指纹”：比较整个指纹，比只看其中一根柱子包含更多信息。
>
> 这是作者从图 1 得到的经验观察，并不是“同类 patch 的分布必然相同”的定理。边界上混合了两种物体的 patch，也可能出现相似指纹；这恰好解释了为什么 CDA 能补全物体，却仍需要 SBE 防止激活越界。图 1 的柱状图是对选定 patch 的示例，不能单凭它推出整个数据集上的统计保证。

受上述发现启发，我们提出类别分布感知（CDA）模块，利用类别分布知识在亲和力中建立精确关系，从而获得更完整的 CAM。具体而言，我们首先生成 CLIP 图像块与文本特征之间的注意力图，然后针对注意力图中的每个图像块，估计其在目标类别和超类上的特定类别分布（引入超类是为了丰富分布表示）。接下来，我们通过 Jensen–Shannon（JS）散度，构建两个图像块与图像中所有其他图像块之间的类别分布相似度图。由于来自同一目标类别的图像块表现出高度相似的类别分布，我们选择性地纳入所构建的相似性与不相似性，对来自 MHSA 的初始亲和力进行校正，得到类别分布感知（CDA）亲和力。该 CDA 亲和力可以有效用于 WSSS，无需进一步训练，就能增强 CAM 准确定位与类别相关图像块的能力。

CDA 亲和力擅长激活更完整的 CAM，但不同目标类别之间的边界区域（图 1(a) 中的“摩托车”和“人”）具有高度相似的类别分布，也可能无意间诱导出较强的关系。这不可避免地会导致 CAM 边界区域过度激活，从而产生不准确的边界监督。为了减轻这一影响，我们还提出超类边界探索（SBE）模块。该模块为最终分割预测提供专门的超类间边界监督，有效解决 CDA 模块尚未解决的边界过度激活问题。具体来说，它将利用 DINO（Distillation with No Labels，无标签蒸馏）图像特征的超原型 CAM，与通过 CLIP 的零样本能力推断出的超类 CAM 相结合。由于 DINO 的图像特征已知能够更好地分离超类区域 [17]，这种结合带来了更准确、更紧致的边界划分。因此，我们使用该超原型 CAM，通过边界增强损失，专门监督不同超类之间的边界分割预测。通过整合所提出的两个模块，我们建立了一种新的有效单阶段图像级 WSSS 框架 CD-CLIP。

本文的贡献总结如下：

- 我们的分析揭示，虽然传统基于 MHSA 的亲和力无法建立可靠的类内关系，但所有类别上的分布能够捕获不同图像块之间更丰富、更有区分力的语义关系。
- 基于上述发现，我们提出 CD-CLIP 框架，其中包括类别分布感知（CDA）模块和超类边界探索（SBE）模块：前者利用每个图像块在所有类别上的类别分布，获得更完整的 CAM；后者为最终分割预测提供更准确的边界监督。
- 实验结果表明，我们的 CD-CLIP 框架优于其他单阶段和多阶段方法，在 PASCAL VOC 2012 验证集上取得 82.5% mIoU，在 MS COCO 验证集上取得 54.1% mIoU。

## 2. 相关工作

### 2.1. 弱监督语义分割

仅使用图像级标注的弱监督语义分割（WSSS）[21, 32, 42, 43] 近年来受到了广泛关注。这一任务的解决方案通常分为两大类：多阶段框架和单阶段框架。在多阶段框架 [16, 20, 60] 中，流程通常包括依次训练分类网络和分割网络。分类网络首先生成初始类激活图（CAM）。随后，使用 IRN [2] 或 PSA [1] 等后处理技术细化这些 CAM，以获得伪标签。之后，在这些伪标签的监督下，训练分割网络预测分割结果。此外，为了解决激活不足问题，基于原型的方法 [4, 6, 11, 45, 56] 旨在改善原型表示，以扩大 CAM 中的激活区域。

相比之下，单阶段框架 [13, 35] 对分类网络与分割网络采用并行训练范式。具体而言，基于 ViT 的方法通常沿用 ToCo [35] 框架，使用图像块 token 对比损失来缓解常见的过度平滑问题。DuPL [46] 通过构建两个子网络，对伪标签中的错误区域进行交叉监督，从而解决伪标签固有的确认偏差问题。此外，WeCLIP [54] 提出了一种专门为单阶段 CLIP 方法设计的稳健冻结骨干网络，并配备了一种用于分割预测的新型 CLIP 特征解码器 [30]。与这些已有工作不同，我们的方法额外整合 DINO 图像特征来生成超原型 CAM，作为超类边界监督。

### 2.2. WSSS 的亲和力学习

亲和力可以理解为捕获图像块（或像素）之间相似关系的矩阵，已广泛应用于弱监督语义分割（WSSS）任务，以提升类激活图（CAM）的性能。特别地，Ahn 等人 [1] 提出了 AffinityNet，这是一种深度神经网络（DNN），在初始判别性局部分割的监督下，学习预测相邻图像坐标之间的语义亲和力。鉴于 Transformer 在 WSSS 中带来的显著性能提升，研究者通过 AFA 模块 [34]，探索了利用多头自注意力（MHSA）中固有的亲和力来细化初始伪标签。不同于这些已有方法，CLIP-ES 利用 CAM 作为类别掩码，在无需任何额外训练的情况下导出逐类亲和力。在这些进展的基础上，我们的工作利用 CLIP 模型中存在的类别分布，揭示更精确的关系，用于后续的 CAM 细化。

> [!note] 我的理解｜这里的 affinity 是传播路径，CAM 是沿路径传递的类别证据
> CAM 为每个位置提供“像不像某一类”的分数；affinity 为每对位置提供“这两个位置应不应该互相影响”的权重。二者不是同一种东西。把一张只有局部高亮的 CAM 放到好的 affinity 上传播，高亮证据就可能扩展到同类物体的其他部位；若 affinity 把人和摩托车连接得太紧，person 的分数也可能传进摩托车区域。
>
> 本文的改进重点不是另外训练一个图像分类器，而是利用冻结 CLIP 已有的多类别响应，重新组织 patch 之间的关系。CDA 改善生成伪标签所依赖的关系；SBE 再给最终分割预测增加一种来自 DINO 的约束。虽然 CLIP 和 DINO 冻结、CDA 本身无需额外训练，分割 decoder 仍然要学习，所以整套 CD-CLIP 是单阶段弱监督训练方法，不能标成整个方法 training-free。

## 3. 方法

本节介绍 CD-CLIP，即我们的弱监督语义分割（WSSS）单阶段框架。如图 2 所示，流程首先生成初始类激活图（CAM）和亲和力，然后使用类别分布感知（CDA）模块，利用亲和力中基于 CLIP 类别分布的关系来细化 CAM。最后，超类边界探索（SBE）模块通过提供更准确的边界监督，缓解这些基于分布的关系所造成的边界缺陷。

![](../../../../../../99_Assets%20(资源文件)/images/CD-CLIP_Figure_2.png)

**图 2. 我们的 CD-CLIP 框架概览。** 首先将图像输入 CLIP 图像编码器与 DINO 编码器，以提取相应特征。同时，将由目标类别和所设计的超类组成的文本提示输入 CLIP 文本编码器，以获得文本特征。随后，利用这些图像与文本特征，基于它们的相似性生成注意力图。在 CAM 生成过程中，我们基于图像特征与文本特征之间的概率推断出两类 CAM。在类别分布感知（CDA）模块中，我们引入 CDA 亲和力以增强 CAM 细化。该亲和力由注意力图内类别分布之间的 JS 散度，以及多头自注意力（MHSA）捕获的初始亲和力共同生成。在超类边界探索（SBE）模块中，我们导出超类原型 CAM，通过边界增强损失提供准确的边界监督。该原型 CAM 使用 DINO 特征和推断出的超类 CAM 生成。解码器则输出最终分割预测，并同时受到由细化后 CAM 和超类原型 CAM 导出的伪标签的监督。

**图片内容解释：** 图中上方的冻结 CLIP 文本编码器与视觉编码器分别提取文本和图像特征；右上方的 CDA 模块将类别分布的 JS 散度与初始 MHSA 亲和力结合，细化 CAM。下方的冻结 DINO 编码器提取特征，经超类 CAM 引导生成超类原型和原型 CAM。右侧解码器输出分割结果，图中红色箭头标示分割损失与边界增强损失的监督位置，蓝色虚线表示梯度路径。

> [!note] 我的理解｜先看清整条数据流：两套伪标签监督同一个分割 decoder
> 训练输入是一张图像，以及“这张图里有哪些目标类”的图像级标签，没有人工像素级分割标签。目标类名称与人工设计的超类名称组成文本提示；同一张图分别送进 CLIP 视觉编码器和 DINO 编码器，文本送进 CLIP 文本编码器。图 2 的三个编码器都有冻结标记，主要要训练的是分割 decoder。
>
> 主路径是：**CLIP 图像/文本特征 → 目标类初始 CAM 与 patch 间初始 affinity → CDA 修正 affinity → 传播并细化目标类 CAM → 目标类伪标签 → 用分割损失监督 decoder。** CDA 所用的“类别分布”来自每个 patch 对目标类及超类文本的响应；它输出的是 patch 对 patch 的关系矩阵，不是最终语义分割结果。
>
> 辅助路径是：**CLIP 超类 CAM 提供类别定位 → 在 DINO 特征上汇聚超类原型 → 用原型与各位置的相似度生成超类原型 CAM → 超类伪标签 → 用条件开启的 Dice 损失监督同一个 decoder。** CLIP 告诉 DINO“要找哪一类区域”，DINO 则提供更适合分隔物体区域的视觉结构。两条路径产生的监督互补：目标类伪标签负责细分类语义，超类伪标签着重约束跨超类区域的分界。
>
> 最终输出来自 **CLIP 图像特征 → decoder → 分割预测** 这条预测路径，不是直接把 DINO 原型 CAM 当成最终结果。论文图示中 DINO 与 CAM 分支主要服务于训练监督；据此可以理解为预测主路径不依赖真实图像级标签。但正文没有逐项列出推理时删去哪些分支，不能把精确的推理执行流程当成已核实的代码事实。实验明确说明推理使用多尺度 `{1.0, 1.5}` 和 Dense CRF，而消融表不使用 Dense CRF。
>
> 还要区分“冻结参数”和“不计算任何梯度”：Grad-CAM 需要类别分数对特征的导数来计算热图，依然可以在冻结模型上完成；这不等于用分割损失更新 CLIP。本文并没有额外的可训练文本提示、教师 EMA 更新或 DINO 微调描述，不应自行补入这些机制。

### 3.1. CAM 与亲和力生成

CAM 因其定位能力而常用于图像级 WSSS，以识别图像中的判别性区域；随后，这些区域被进一步细化为伪标签，作为像素级监督。在我们的方法中，我们遵循 GradCAM [27] 来生成初始 CAM。形式化地，给定图像 $\mathbf{X}\in\mathbb{R}^{3\times H\times W}$ 与 $C$ 个类别的文本提示，我们分别从图像编码器和文本编码器输出图像特征 $\mathbf{F}\in\mathbb{R}^{d\times h\times w}$ 与文本特征 $\mathbf{T}\in\mathbb{R}^{C\times d}$，其中 $d$ 为特征维度，$h$ 和 $w$ 为空间尺寸。随后，通过图像特征与文本特征之间的距离计算类别 logits，类别索引 $c$ 对应的初始 CAM $\mathbf{M}_{init}^{c}$ 表示为：

$$
\mathbf{M}_{init}^{c}=\operatorname{ReLU}\left(\sum_k\mathbf{W}_{k}^{c}\mathbf{V}^{k}\right),
\tag{1}
$$

其中，$\mathbf{W}_{k}^{c}$ 表示类别 $c$ 在特征图 $k$ 中的权重，它由类别 logits 与特征图之间的梯度获得。$\mathbf{V}^{k}$ 是特征图 $k$ 的激活值，$\operatorname{ReLU}(\cdot)$ 函数用于消除负值。此外，我们为目标类别设计一个包含 $N$ 个超类（例如“交通工具”和“动物”）的超类集合 $\mathbf{D}_{s}$，并通过文本编码器汇集它们的类别信息。这样，我们不仅利用超类信息为 CDA 模块提供更丰富的类别分布，还通过式 (1) 推断超类 CAM $\mathbf{M}_{s}^{n}$，作为后续 SBE 模块的指导。

> [!note] 我的理解｜先弄清“超类”：把细类别按语义归成更粗的组
> **超类（super-class）就是人为规定的粗类别，没有“超级类别”的特殊含义。** 可以用 `cat、dog → animal`、`car、bus、motorbike → vehicle` 来理解；`person` 则可以单独保留成一组。VOC 上作者选了五个超类：`animal、vehicle、household item、furniture、person`。这套分组由作者设计，不是 DINO 自动发现的，也不是训练中新学出来的类别；最终分割仍然输出原来的细类别。
>
> 同一套超类在后面有两种用途，读的时候要分开：
>
> - **在 3.2 的 CDA 中，超类是额外的语义参照词。** 每个 patch 除了回答“我有多像 cat、dog……”，还回答“我有多像 animal、vehicle……”。这些响应一起用于比较两个 patch 像不像。这里是把粗类别的响应追加到细类别响应后面，不是先把 cat、dog 的得分加起来变成 animal，也不是先把每个 patch 判成某个超类。
> - **在 3.3 的 SBE 中，超类是辅助监督的粗分组。** CLIP 的超类 CAM 先提供大致位置，再从这些位置汇聚 DINO 特征形成原型，用原型找出更完整的粗类别区域，生成超类伪标签来监督 decoder。例如 person 与 vehicle 的分界可以约束“人”的激活不要扩到摩托车上；但 cat 与 dog 都属于 animal，这份监督不能告诉模型哪里是猫、哪里是狗。
>
> 这不是唯一正确的语义分类体系：person 可以独立成组，household item 与 furniture 的具体归属也需要人为规定。上面的映射用于说明概念，主文没有列全 VOC 的细类到超类对应表，不宜自行补全。表 5 的消融说明五类方案在作者比较的三套方案中表现最好，不能证明它是所有可能分组中的最优解。

> [!note] 我的理解｜Grad-CAM 是给特征通道加权，不是直接把余弦相似度当成 CAM
> 式 (1) 在做的事是：先判断哪些视觉特征通道对类别 $c$ 有帮助，再把这些通道的空间响应按重要程度叠加。若第 $k$ 个通道的空间特征图为 $\mathbf V^k\in\mathbb R^{h\times w}$，类别相关权重为标量 $\mathbf W_k^c$，那么 $\sum_k\mathbf W_k^c\mathbf V^k$ 仍是一张 $h\times w$ 热图；ReLU 将负值截成 0，保留对该类提供正向证据的位置。
>
> 例如某位置两个通道的激活为 $(2,1)$，对 person 的权重为 $(0.8,-0.3)$，该位置的 person 热度就是 $\max(0,0.8\times2-0.3\times1)=1.3$。同一组视觉通道换成 bicycle 的权重，得到的就是另一张 CAM。因此 CAM 的类别性主要来自这些类别相关权重，而不是视觉特征换了一遍。
>
> 正文只说权重由类别 logit 与特征图之间的梯度得到。常见 Grad-CAM 会对该梯度做空间平均得到通道权重，但本文没有在式 (1) 中展开具体求导层、平均规则、prompt 模板与 logit 计算细节，不能把通用定义当成已核实的作者实现。式 (3) 的图文余弦响应图也应与这里的 Grad-CAM 区分：前者用于构造类别分布，后者提供待传播的类别激活。
>
> 对超类同样可以执行这套操作：将文本类别从 cat 换为 animal，就可得到超类 CAM $\mathbf M_s^n$，为 SBE 的原型池化提供定位。CDA 使用的则是超类文本与 patch 的余弦响应（式 (3)），不能把这两种图混为一谈。

与此同时，我们还从图像编码器中的 MHSA 提取所有注意力权重 $\mathbf{A}\in\mathbb{R}^{hw\times hw}$，以计算初始亲和力 $\mathbf{A}_{init}$：

$$
\mathbf{A}_{init}=\frac{\operatorname{Sinkhorn}(\mathbf{A})+\operatorname{Sinkhorn}(\mathbf{A})^{\mathrm{T}}}{2},
\tag{2}
$$

其中，$\operatorname{Sinkhorn}(\cdot)$ 表示 Sinkhorn 归一化 [36]。$\mathbf{A}_{init}$ 捕获图像块之间的长程语义关系。然而，如图 1(a) 所示，$\mathbf{A}_{init}$ 中的这些语义关系往往不准确，无法激活目标类别的所有区域，因此在 CAM 细化中不能达到理想的定位效果。

> [!note] 我的理解｜初始 affinity 把注意力整理成一张 patch 关系图
> 为免和超类数 $N$ 混淆，下面把图像 patch 数记为 $L=hw$。初始注意力与 affinity 都是 $L\times L$ 矩阵，第 $(i,j)$ 个元素对应位置 $i$ 与位置 $j$ 的关系。它们不是 $C\times h\times w$ 的分类热图；即使图像只有一个目标类，也有一整张 patch 关系矩阵。
>
> 式 (2) 先对注意力矩阵做 Sinkhorn 归一化，再与转置取平均。Sinkhorn 可以理解为交替校正行和、列和，使不同位置的连接总量更平衡；与转置平均则把“$i$ 关注 $j$”和“$j$ 关注 $i$”合成一个对称关系。例如归一化后两方向的值分别为 0.8 和 0.2，对称化后两格都是 0.5。若 Sinkhorn 已收敛到双随机矩阵，对称化后仍有相应的行列归一性质；具体迭代次数与数值误差处理正文未给出。
>
> 归一化和对称化只是整理已有连接，并不能保证连接在语义上正确。CLIP 自注意力原本服务于图文表示学习，不是专门以像素分割边界为目标学出来的，因此仍可能遗漏同一个物体的另一部分，也可能连接相邻但不同类的物体。CDA 正是要引入额外的语义分布线索来改善这些关系。正文也没有交代多层、多头注意力最终怎样汇成这里唯一的 $\mathbf A$，不要自行认定为“所有层所有头直接平均”。

### 3.2. 类别分布感知（CDA）

> [!note] 大白话先读｜先找出哪些位置像“自己人”，再把 CAM 的亮区传过去
> **3.2 要解决的是：同一个物体已经亮了一部分，怎样让剩下的部分也亮起来？** 例如 person 的初始 CAM 主要照亮躯干，头和腿却很暗。3.1 已经从 CLIP 注意力得到一张 patch 关系图，但它未必能把躯干、头和腿正确连起来。CDA 就利用每个 patch 对一整组类别词的响应，重新调整这张关系图。
>
> **第一步：给每个 patch 列一张“语义响应表”（式 (3)）。** 不只问它“像不像 person”，还让它分别与 cat、dog、car 等目标类，以及 animal、vehicle 等超类的文本特征比较。得到的每一行都是一个 patch 对这些词的响应。这里的“所有类别”指用于构造分布的目标类与超类词表，不是说这些物体都真的出现在这张图里。没出现的类别也可以充当比较参照。
>
> **第二步：比较两张响应表的整体样子（式 (4)）。** 先用 Softmax 把一个 patch 的整串响应变成总和为 1 的比例，再用 JS 散度比较两个 patch 的比例分配。JS 越小，说明两串响应越像。躯干的 person 分数高、头部的 person 分数低，并不妨碍它们对其他类别的相对响应仍有共同特点；作者希望靠这些额外线索把它们联系起来。这里依赖的是经验上有用的相似性，不是“同类的分布一定相同”。
>
> **超类就在前两步里增加观察角度。** 比如猫的头和躯干对 cat 的响应可能差别较大，但对 animal 都有明显响应，这个额外维度就可能帮助识别共同语义。cat 和 animal 可以同时描述一个位置，所以 Softmax 后的“类别分布”更适合理解为“一组语义词的相对响应分布”，不能直接当成互斥细类别的真实概率。超类也不保证有帮助：猫和狗都对 animal 响应高，仍需要其他维度提供区分。
>
> **第三步：用分布相似性调整原来的 patch 关系（式 (5)）。** 先把“分布有多像”转换成关系权重，再与 3.1 的初始亲和力结合，得到 CDA 亲和力。直观上，是让原来的视觉连接多参考一份语义证据。不要把它想成“相似就连线、不相似就删线”的硬规则；按公式通常的矩阵乘法读法，它是在组合关系，具体解释见下方式 (5) 注释。
>
> **第四步：沿调整后的关系传播原来的 CAM（式 (6)）。** 如果躯干与头、腿的联系得到改善，躯干已有的 person 激活就能传过去，让人的热图更完整。这一步传播的仍是 person、cat 等原有目标类的激活，没有把最终任务改成超类分割。
>
> 可以把整条流程记成：**每个 patch 对各类词的响应 → 比较整串响应 → 调整 patch 间关系 → 沿关系传播 CAM。** 两次 Softmax 分别回答不同问题：第一次整理“这个位置对各个词的响应比例”，第二次整理“这个位置与其他位置的关联权重”。本节利用 CLIP 的信息，DINO 到 3.3 的 SBE 才介入；CDA 可能让人的激活传到摩托车上，因此还需要后续的跨超类区域监督来约束部分边界。

如第 1 节所述，CLIP 中完整的类别分布 [18] 包含有价值的语义信息，能够建立更精确、更全面的图像块间关系。因此，我们设计 CDA 模块，利用这种类别分布知识建立更强的亲和力，有效解决由初始亲和力 $\mathbf{A}_{init}$ 细化后的 CAM 所存在的激活不足问题。

具体而言，我们首先生成图像特征 $\mathbf{F}$ 与所有文本特征 $\mathbf{T}_{all}\in\mathbb{R}^{|C+N|\times d}$（目标类别和所设计的超类）之间的注意力图 $\mathbf{S}_{a}$，如下所示：

$$
\mathbf{S}_{a}=\operatorname{Min\text{-}max}\left(\operatorname{CosSim}(\mathbf{F},\mathbf{T}_{all})\right),
\tag{3}
$$

其中，$\operatorname{Min\text{-}max}(\cdot)$ 为 Min-max 归一化，$\operatorname{CosSim}(\cdot)$ 为余弦相似度函数。为了丰富类别分布表示，我们还纳入了超类信息。注意力图 $\mathbf{S}_{a}$ 中的每个图像块都携带一个与不同类别语义相对应的得分分布。于是，类别分布相似度图 $\mathbf{S}_{d}$ 可以定义为：

$$
\mathbf{S}_{d}=\frac{1-\mathbf{D}_{JS}\left(\operatorname{Softmax}(\mathbf{S}_{a})\|\operatorname{Softmax}(\mathbf{S}_{a})^{\mathrm{T}}\right)}{\tau},
\tag{4}
$$

其中，$\operatorname{Softmax}(\cdot)$ 用于估计 $\mathbf{S}_{a}$ 中所有图像块的类别分布概率。$\mathbf{D}_{JS}(\cdot\|\cdot)$ 为 Jensen–Shannon（JS）散度，它是一种取值有限且对称的度量，用于衡量两两相似性。两个类别分布越相似，对应的 JS 散度就越小。$\tau$ 是用于控制软化程度的温度。

> [!note] 我的理解｜先把每个 patch 变成一个包含目标类与超类的响应向量
> 设目标类数为 $C$，超类数为 $N$，总文本条目数为 $K=C+N$。将视觉特征按空间位置展开为 $L\times d$，全部文本特征是 $K\times d$。逐个计算图文余弦相似度，就得到 $L\times K$ 的表：一行对应一个 patch，一列对应一种文本类别。比如一行可以依次表示这个位置对 cat、dog、person、animal、vehicle 的响应。
>
> 余弦相似度比较两个向量的方向，通常写成 $s_{ik}=\langle\mathbf f_i,\mathbf t_k\rangle/(\|\mathbf f_i\|\|\mathbf t_k\|)$。式 (3) 再进行 Min-max 归一化得到 $\mathbf S_a$。论文没有明确 Min-max 是对每个类别的整张空间图、每个 patch 的类别向量，还是其他范围进行，因此具体归一化轴属于未说明细节。不同选择会改变后面的类别分布，不能略过这个区别。
>
> 这里把 cat 与 animal 同时放进向量，并不要求类别之间互斥：同一个猫 patch 同时对两个词响应很高是合理的。后续 Softmax 只是把这些相关语义探针的响应整理成可比较的概率向量，不应将其直接解释成“真实、互斥类别的校准后验概率”。超类在此提供较宽泛的语义参照；它们具体如何划分，则还会影响 SBE 的监督粒度。

> [!note] 我的理解｜JS 比较的是两个 patch 各自的类别分布，类别轴不能和空间轴混淆
> 大白话说，先把每个 patch 的整串类别得分变成“总和为 1 的响应比例”，再看两个 patch 的比例分配像不像。按照正文“每个 patch 上的类别分布”的语义，第一处 Softmax 应在 $K=C+N$ 个类别上计算：$p_i(k)=\exp(S_a(i,k))/\sum_{r=1}^{K}\exp(S_a(i,r))$。这样 $p_i$ 长度为 $K$，同一 patch 的 $K$ 项和为 1。若沿 $L$ 个空间位置归一化，得到的会是“某一类在图中怎么分布”，不再是这里所讨论的对象。
>
> 对任意位置 $i,j$，令 $m=(p_i+p_j)/2$，JS 散度可展开为 $D_{\mathrm{JS}}(p_i\|p_j)=\tfrac12\sum_k p_i(k)\log[p_i(k)/m(k)]+\tfrac12\sum_k p_j(k)\log[p_j(k)/m(k)]$。它先建立两个分布的平均参照，再衡量各自偏离这个参照的程度；完全相同的分布散度为 0。对所有位置对做这件事，就从 $L\times K$ 的类别响应表得到 $L\times L$ 的位置关系表。
>
> 比如两个 patch 的分布是 $(0.45,0.35,0.20)$ 与 $(0.40,0.35,0.25)$，虽然第一个类别的得分不同，整体分配仍相近，JS 很小；与 $(0.10,0.10,0.80)$ 相比，整体重心明显改变，JS 就更大。这是纯粹帮助理解散度的示意数值，并非本文图 1 的实测概率。它也说明 CDA 使用的是整串相对响应，而非要求两个 patch 必须共享相同的最高分或相同的目标类分数。
>
> 式 (4) 中的转置记号应理解为“构造所有 patch 对并比较”，不能将一个 $L\times K$ 表和它的 $K\times L$ 转置直接当作两个同形概率分布求 KL。公式是 pairwise 运算的紧凑记法。正文未给 JS 的对数底数、数值稳定处理与精确张量布局；这里对类别轴的解释由正文语义确定，不是源码核实结果。
>
> 最后的 $S_d(i,j)=[1-D_{\mathrm{JS}}(p_i\|p_j)]/\tau$ 把“小散度”转换为“大相似度”。用以 2 为底的对数时 JS 上界为 1，用自然对数时上界为 $\log2$；作者只写 JS 而未指定底数，因此不能无条件宣称 $1-D_{\mathrm{JS}}$ 恰好覆盖整个 $[0,1]$。若接下来对该行做 Softmax，统一加上的 $1/\tau$ 会抵消，实质权重与 $\exp[-D_{\mathrm{JS}}/\tau]$ 成正比。也就是说，$\tau$ 越小越偏向分布最相近的位置；它并不直接改变前一步类别分布的 Softmax。
>
> 例如两个候选位置的 JS 散度相差 0.1，在 $\tau=1$ 时，较相似位置与较不相似位置的权重比约为 $e^{0.1}=1.11$；在 $\tau=0.1$ 时，这个比值变成 $e^1=2.72$。温度放大了“更像一些”的差别，但不会把错误的语义关系自动变正确。以上温度仅为解释性例子，正文未报告所用 $\tau$ 数值。

由于具有相同类别语义的图像块表现出相似的类别分布，我们希望利用 $\mathbf{S}_{d}$ 中基于分布的相似性来校正初始亲和力。具体而言，通过突出同一类别内图像块之间的关系，并忽略不同类别图像块之间的关系，我们得到类别分布感知（CDA）亲和力 $\mathbf{A}_{d}$：

$$
\mathbf{A}_{d}=\operatorname{Softmax}(\mathbf{S}_{d})\cdot\mathbf{A}_{init},
\tag{5}
$$

其中，初始亲和力 $\mathbf{A}_{init}$ 中所有不准确的关系均通过基于分布的相似性 $\mathbf{S}_{d}$ 得到校正。

> [!note] 我的理解｜第二次 Softmax 在 patch 关系上工作，但融合细节仍需保持边界
> 到这里 $\mathbf S_d$ 已经是 $L\times L$ 的位置关系表。为了让每个位置对其他位置分配关系权重，式 (5) 的 Softmax 自然应作用在“候选关联位置”的轴上。这与式 (4) 生成类别概率时的 Softmax 不同：前者回答“这个 patch 更愿意与哪些 patch 交换信息”，后者回答“这个 patch 对哪些文本类别响应更高”。论文没有标注具体 `dim`，因此只能按这一语义解释，不能声称已核对作者的张量维度实现。
>
> 式 (5) 原文是 $\mathbf A_d=\operatorname{Softmax}(\mathbf S_d)\cdot\mathbf A_{init}$。按通常矩阵记法，令 $\mathbf B=\operatorname{Softmax}(\mathbf S_d)$，则 $(\mathbf A_d)_{ij}=\sum_{k=1}^{L}B_{ik}(A_{init})_{kj}$：位置 $i$ 先找到分布相似的位置 $k$，再综合这些位置在原始 affinity 中通向 $j$ 的关系。这是一种关系组合，形状仍为 $L\times L$。例如 $\mathbf B$ 的某一行对两个中间位置分配 $(0.8,0.2)$，它对应的最终关系行就是那两行初始 affinity 的加权和。
>
> 但正文又使用了“突出同类关系、忽略不同类关系”的语言，没有明确声明这里的点号是矩阵乘法还是逐元素融合。如果解释成逐元素门控，则每条边会变成 $B_{ij}(A_{init})_{ij}$，机制与上述矩阵组合不同，还涉及之后是否重新归一化的问题。式 (7) 明确使用 $\odot$ 表示掩膜乘法，使式 (5) 的矩阵乘法读法较自然；不过本次没有读源码，仍不能把实现类型说死。
>
> 公式未给出额外的硬阈值筛边规则。“所有错误关系都被纠正”是作者对效果的表述，不是式 (5) 能保证的性质；边界处不同类的分布仍可能相似，这正是后续 SBE 的动机。

此后，这种 CDA 亲和力可以通过以下过程精确地细化 CAM：

$$
\mathbf{M}_{re}^{c}=\mathbf{M}_{init}^{c}\cdot(\mathbf{A}_{d})^{t}.
\tag{6}
$$

其中，$\mathbf{M}_{re}^{c}$ 是细化后的 CAM，$t$ 为细化迭代次数。在这一过程中，具有较强关系的图像块往往具有相同的类别语义，并在 CAM 上被激活。

通过这种方式，我们的 CDA 模块利用图像块之间的类别分布关系，生成精确且稳健的 CDA 亲和力。这种亲和力有助于解决激活不足问题，并改善 CAM 细化过程中的定位能力，从而能够导出高质量伪标签，实现有效监督。

> [!note] 我的理解｜CAM 细化就是让已有的类别证据沿关系图逐步传播
> 将某一类的初始 CAM 展开为行向量 $\mathbf m_{init}^c\in\mathbb R^{1\times L}$，式 (6) 就是 $\mathbf m_{re}^c=\mathbf m_{init}^c(\mathbf A_d)^t$，结果再排回 $h\times w$。这里上标 $t$ 是迭代次数，即连续做 $t$ 次矩阵乘法，不是转置；转置在式 (2) 中另用 $\mathrm T$ 标出。
>
> 一次传播时，位置 $j$ 得到的新分数为 $m_{new}^c(j)=\sum_i m_{old}^c(i)(A_d)_{ij}$。例如初始 person CAM 只有躯干高亮，为 $(1,0,0)$；若躯干向头、腿的传播权重是 $(0.5,0.3,0.2)$，一次之后便得到 $(0.5,0.3,0.2)$。头与腿即使原本对 person 响应不强，只要与躯干建立了合适联系，也能接收到类别证据。
>
> 多次传播能到达更远的关联位置，但也会累积错误连接：如果人体边缘与摩托车边缘被连接，person 热度就可能越界。因此 $t$ 控制传播范围与过度平滑之间的折中；正文只定义了这个参数，没有给出其具体取值或停止规则。最终将热图变成像素伪标签还需要类别竞争、背景处理及可能的置信度筛选，正文没有展开这些步骤的阈值，不能凭常见 WSSS 做法替作者补齐。
>
> 这一机制同时解释了 CDA 的收益与代价：它能让 CAM 更完整，却不自动拥有精细边界。CDA 输出的关系矩阵在式 (6) 中供各目标类 CAM 使用，而不是每个目标类另外生成一套有明确公式的专属 affinity。

### 3.3. 超类边界探索（SBE）

> [!note] 大白话先读｜用 CLIP 指路，让 DINO 找区域，再教分割器把两边分开
> **3.3 要解决的是：CDA 把物体补完整时，可能顺手把旁边的物体也涂进来了。** 继续看“人骑摩托车”：人的 CAM 本来只亮躯干，CDA 帮它扩到了头和腿，但也可能扩到摩托车上。SBE 于是另外做一份较粗的区域判断：“这边是 person，那边是 vehicle”，用它给最终分割器增加约束。
>
> **为什么还要请 DINO 帮忙？** CLIP 能根据文字提示指出“人、交通工具大概在哪里”；DINO 的视觉特征则能提供另一种区域结构线索，帮助判断哪些位置看起来属于同一片区域。但 DINO 特征本身没有贴上 person、vehicle 这些名字，因此需要 CLIP 先提供带类别含义的取样位置。这里用的是冻结编码器已有的能力。
>
> **第一步：CLIP 先给出粗类别的位置线索。** 用 person、vehicle 等超类文本生成超类 CAM $\mathbf M_s^n$。把它理解为一张不一定准确的提示图：“这些位置比较像人，那些位置比较像交通工具。”这张图为后面的取样提供依据，并不是最终的超类伪标签。
>
> **第二步：从提示区域里提炼一个“代表特征”（式 (7)）。** 按照 person 的提示区域，把对应位置的 DINO 特征汇聚起来，得到当前图像中 person 的代表向量；vehicle 也同样处理。这个代表向量就叫**超类原型**。例如人上半身的定位比较可靠，就可以从这些位置提取线索，再去找其他与它相似的位置。CAP 可以先理解为“对这个类别区域里的特征求平均”；具体如何加权、取样见下方公式注释。
>
> **第三步：拿代表特征去找整张图中相似的位置（式 (8)）。** 将 person 原型与每个位置的 DINO 特征比较，越相似，person 的原型 CAM $\mathbf M_p^n$ 就越亮；负相似度由 ReLU 截成 0。这样，即使某处没被最初的 CLIP CAM 明显照亮，只要它的 DINO 特征与原型接近，也有机会被找回来。vehicle 原型同样得到自己的响应图。作者希望利用这些图形成更完整、分界更清楚的粗类别区域，但效果仍取决于取样和特征是否可靠。
>
> **第四步：把粗区域变成伪标签，辅助训练 decoder（式 (9)）。** 从超类原型 CAM 导出 $\mathbf Y_s$，再用 Dice 损失鼓励分割预测与这些粗区域重合。例如某块摩托车区域被分成了 person，vehicle 的区域监督就能提供纠偏信号。这里直接被约束的是 decoder 的预测，不能把它理解成拿 DINO 掩膜直接裁掉 CDA 热图的越界部分。decoder 仍输出原来的细类；计算超类损失时需要对齐类别空间，主文未展开具体实现，下方保留了这一说明。
>
> **这份额外监督有开启条件：当前图像至少包含两个不同超类。** 作者从图像级标签映射出超类集合：`{person, motorbike} → {person, vehicle}`，满足条件；`{cat, dog} → {animal}`，只有一个超类，按式 (9) 这项损失为 0。后者仍照常接受细类别分割监督，并不是整张图不参加训练。两个超类出现在同一张图里，也不意味着它们一定接触；这里是按标签筛选样本。
>
> **为什么叫“边界增强”，却在比较整片区域？** 因为让 person、vehicle 各自占据正确的区域，就有机会改善两者的分界。式 (9) 用的是区域重叠损失，没有单独画一条边缘线，也没有规定只在边界几个像素上算损失。它能辅助区分跨超类的区域，却不能靠 animal 标签分清猫和狗。
>
> 把两节连起来看：**CDA 提供更完整的细类 CAM 及其伪标签；SBE 另外提供带有 DINO 结构线索的超类伪标签。两份监督一起训练最终分割器。** SBE 的流程是“CLIP 粗定位 → 汇聚 DINO 特征得到原型 → 用原型找区域 → 超类伪标签 → 辅助监督 decoder”。

尽管我们的 CDA 模块能够建立精确的类内关系，但对于不同目标类别之间所建立的强关系，仍可能存在持续未解的问题。这可能导致 CAM 边界过度激活，从而产生不准确的边界监督。为了解决 CDA 模块尚未解决的这一问题，我们引入一个互补的超类边界探索（SBE）模块。

不同于常规 WSSS 特征，DINO 特征在超类区域分割方面表现出更强的表示能力 [17]。因此，我们的 SBE 模块将 DINO 的分割优势与类别感知的激活相结合，通过生成超类原型 CAM 来捕获完整的超类区域与精确边界。该超类原型 CAM 被进一步用于监督最终分割预测，减轻过度激活的影响。

> [!note] 我的理解｜SBE 用粗类别的可靠边界，修正细类别伪标签的越界问题
> CDA 问的是“哪些 patch 的语义响应像”，这种关系在边界混合区域可能失真；SBE 则另外问“在 DINO 的视觉结构中，哪些位置属于同一片粗类别区域”。它没有继续只依赖 CLIP affinity，而是引入一份来源不同的结构证据，给 decoder 一个纠偏信号。
>
> 这里的超类是对目标类的人工归组，例如 cat、dog 属于 animal，摩托车属于 vehicle，而 person 自身作为一组。假如 person 的 CAM 泄漏到摩托车上，person 与 vehicle 的超类伪标签可以给出另一条分界；但 cat 与 dog 都归入 animal，超类监督本身就不能强迫二者分开。细类内部的区分仍主要依赖目标类伪标签和分割学习。
>
> 因而“边界增强”应理解为利用区域级超类监督改善跨超类分界，不是本文训练了一个显式边缘检测头，也不是公式里只在几像素宽的边界带上计算损失。正文给出的式 (9) 是对所选样本的 Dice 损失，没有额外边缘提取算子、轮廓距离项或边界带权重公式。

然而，DINO 特征无法为 WSSS 任务提供特定类别的定位。为了解决这一问题，我们首先将 CLIP 模型推断出的超类 CAM $\mathbf{M}_{s}^{n}$ 用作特定类别掩码，并基于 DINO 图像特征 $\mathbf{F}_{d}\in\mathbb{R}^{d\times h\times w}$ 计算超类原型，该过程定义为：

$$
\mathbf{f}_{s}^{n}=\operatorname{CAP}\left(\mathbf{M}_{s}^{n}\odot\mathbf{F}_{d}\right),
\tag{7}
$$

其中，$\mathbf{f}_{s}^{n}$ 是每个超类的超类原型，$\operatorname{CAP}(\cdot)$ 表示类别平均池化操作。

> [!note] 我的理解｜CLIP 提供“从哪里取样”，DINO 提供“取到什么视觉表示”
> DINO 特征擅长表达区域结构，但单看一堆向量并不知道哪一堆叫 animal。CLIP 超类 CAM $\mathbf M_s^n$ 相当于给 DINO 一张取样地图：在 animal 响应强的位置多取一些视觉特征，然后汇聚成当前图像中 animal 的代表向量，这就是超类原型 $\mathbf f_s^n$。
>
> 为避免把两种编码器的通道数混为一谈，可将 DINO 特征写成 $\mathbf F_d\in\mathbb R^{d_D\times h_D\times w_D}$。在已经完成空间对齐的前提下，超类掩膜是 $h_D\times w_D$，它在通道轴广播后与 DINO 特征逐位置相乘；CAP 再沿空间位置汇聚，输出一个 $d_D$ 维向量。$N$ 个超类最多得到 $N\times d_D$ 的原型表，不需要把 CLIP 文本向量直接变成 DINO 向量。
>
> 常见的加权区域平均可以写成 $\mathbf f_s^n=\sum_i m_i^n\mathbf f_{d,i}/(\sum_i m_i^n+\epsilon)$。例如一个超类掩膜只选择了两处，DINO 特征分别是 $(1,0)$ 和 $(0.8,0.2)$，等权平均的原型就是 $(0.9,0.1)$；若第二处权重较低，原型会更接近第一处。这一展开只是帮助理解 CAP 的通常含义：论文式 (7) 只写 $\operatorname{CAP}(\mathbf M_s^n\odot\mathbf F_d)$，没有明确给出软掩膜还是阈值二值掩膜、分母、空区域处理等规则。
>
> 对后续的余弦相似度而言，原型整体乘上一个正标量不会改变方向，因此仅仅改变非零原型的统一归一化因子，通常不会改变式 (8) 的余弦结果。真正关键的是从哪些位置取样、各位置的相对权重，以及取样区域是否被其他类污染；不必把所有 CAP 写法差异都误解为同等重要。
>
> 这个原型是当前图像的区域代表，不是论文明示的跨图像类别记忆库，也没有 EMA 更新过程。原型来自有噪声的 CLIP 定位，因此不是天然无误：若取样区域严重混入其他类，代表向量也可能被污染。正文使用 $\mathbf M_s^n$ 指代推断出的超类 CAM，没有明确写出它在式 (7) 前是否必定经过与目标类 CAM 完全相同的 CDA 传播步骤，不能把这一点补成确定流程。

接下来，考虑到超类原型能够有效捕获各自的超类语义，我们通过计算 $\mathbf{f}_{s}^{n}$ 与 DINO 图像特征 $\mathbf{F}_{d}$ 中每个图像块之间的相似度，生成超类原型 CAM $\mathbf{M}_{p}^{n}$：

$$
\mathbf{M}_{p}^{n}=\operatorname{ReLU}\left(\operatorname{CosSim}(\mathbf{f}_{s}^{n},\mathbf{F}_{d})\right),
\tag{8}
$$

与初始 CAM $\mathbf{M}_{init}^{c}$ 相比，包含 DINO 特征知识的超类原型 CAM $\mathbf{M}_{p}^{n}$ 在超类之间具有更准确的边界激活。

> [!note] 我的理解｜原型再去扫描整张 DINO 特征图，找回属于该区域的其他位置
> 得到超类原型后，式 (8) 让它与每个 DINO patch 做余弦相似度。两者都处于 DINO 特征空间，维数都是 $d_D$，所以可以直接比较方向；得到 $h_D\times w_D$ 的相似度图，再经 ReLU 去掉负相似度，就形成该超类的原型 CAM。这里没有把 CLIP 特征与 DINO 特征逐通道相加或直接点乘。
>
> 例如原型为 $(0.9,0.1)$，某个原本没被 CLIP CAM 强烈激活的位置特征是 $(0.8,0.2)$，其方向与原型接近，也会得到较高响应；方向近乎相反的位置则被 ReLU 截断。这样 CLIP 只需提供较可信的起点，DINO 的结构相似性就有机会找回更完整区域。与 CDA 的多步 patch 图传播相比，这里更像“拿一个区域代表去检索所有位置”；二者利用相似性的对象不同。
>
> **必须注意空间对齐。** 正文为 CLIP 写入 $320\times320$ 输入、patch size 16，为 DINOv2 写入 $308\times308$ 输入、patch size 14。若按普通 patch 切分计算，二者分别对应 $20\times20$ 与 $22\times22$ 的网格。因此论文虽然在公式中都简记成 $h\times w$，真正做掩膜乘法及伪标签监督前仍需要空间对齐；正文没有说明插值发生在哪一支、采用何种插值，或者是否还有其他分辨率变换。这里只能确认必须对齐，不能写成作者明确使用了某一种 resize。
>
> 论文也没有说明把多个超类原型 CAM 转成 $\mathbf Y_s$ 时怎样设置背景、拒绝低置信度位置及处理重叠。式 (8) 定义的是热图，式 (9) 使用的是伪标签，中间离散化步骤不能当作已经完整给出了。

为了在尽量降低计算成本的同时保证监督准确，我们专注于监督包含超类间边界的分割预测。为此，我们需要识别解码器输出的每个分割预测中出现的超类。具体而言，我们利用目标类别标签与所设计的超类集合 $\mathbf{D}_{s}$ 来确定出现的超类。对于每个预测，我们根据类别标签检查出现的类别数量。如果存在多个类别，我们将它们映射到集合中对应的超类（例如，“猫”属于“动物”）。这样，我们就能够获得每个预测中出现的超类集合 $\mathbf{C}_{p}$。

> [!note] 我的理解｜开启辅助监督看的是超类数量，不能只数图里有几个细类
> 作者先利用图像级目标类标签，再通过预先设计的对应关系，得到当前样本出现的超类集合 $\mathbf C_p$。因此“出现了哪些类”并不是从 decoder 的 argmax 预测反推的，也不是需要额外人工标出一张超类像素图；它可以从已有的图像级标签映射出来。
>
> 例如图像标签为 `{cat, dog}`，映射后只有 `{animal}`，$|\mathbf C_p|=1$，按式 (9) 不开启 $\mathcal L_b$。图像标签为 `{cat, person}`，映射为 `{animal, person}`，$|\mathbf C_p|=2$，开启辅助监督。`{car, bus, bicycle}` 虽然有三个细类，若都归入 vehicle，仍只算一个超类。去重是集合这个概念本身要求的，不能把同一超类重复计数。
>
> 这是一种由图像级标签驱动的样本选择近似：存在两个超类，不保证它们在空间上一定相接；作者也没有给出通过真实轮廓检测来确认接触边界的过程。其目的，是把超类结构约束重点用于更可能包含跨超类边界的样本。

随后，我们使用 $\mathbf{M}_{p}^{n}$ 导出伪标签 $\mathbf{Y}_{s}$。对于包含多个超类的预测，我们通过所设计的边界增强损失 $\mathcal{L}_{b}$ 提供超类边界监督，其计算如下：

$$
\mathcal{L}_{b}=\begin{cases}
\operatorname{Dice}(\mathbf{P},\mathbf{Y}_{s})&\text{若 }|\mathbf{C}_{p}|\geq 2,\\
0&\text{其他情况。}
\end{cases}
\tag{9}
$$

其中，$\mathbf{P}$ 为分割预测，$\operatorname{Dice}(\cdot,\cdot)$ 表示 Dice 损失，$|\mathbf{C}_{p}|$ 表示当前预测 $\mathbf{P}$ 中出现的超类数量。通过使用 $\mathcal{L}_{b}$，我们利用 DINO 的图像知识，有效监督超类之间的边界预测。这鼓励解码器避开过度激活的边界区域，从而产生更完整、更可靠的分割预测。

> [!note] 我的理解｜Dice 要先在同一种类别空间里比较，细类怎样归组是正文留下的缺口
> 式 (9) 的整体意思很直观：当当前图像至少出现两个超类时，让 decoder 的预测与 DINO 引导得到的超类伪标签尽量重合；否则这项损失取 0。Dice 关注预测区域与目标区域的重叠。一个常见的单类软 Dice 示例是 $1-[2\sum_i p_i y_i+\epsilon]/[\sum_i p_i+\sum_i y_i+\epsilon]$，但多类平均方式、平滑项与是否包含背景，本文没有给具体定义，这个展开不应当作作者的精确损失实现。
>
> 真正需要追问的是：decoder 输出目标细类，$\mathbf Y_s$ 却是超类标签，二者的通道语义通常不一致，不能不加处理就直接求多类 Dice。一个数学上自然的解释，是先把属于同一超类的细类概率相加：若 $g(c)$ 表示细类到超类的映射，则 $\tilde p_n(i)=\sum_{c:g(c)=n}p_c(i)$，再拿 $\tilde p_n$ 与超类标签比较。例如某位置 $p_{cat}=0.3,p_{dog}=0.2,p_{person}=0.4,p_{bg}=0.1$，归组后的 animal 概率就是 0.5。
>
> **上述概率求和是解释该目标如何成立的一种合理方式，正文没有提供这个归组公式，也没有说明实际是合并概率、合并 logits，还是采用其他损失组织方式。** 这几种做法并不等价；尤其不能将“概率相加”和“logits 相加后再 Softmax”混为一谈。背景如何对应、未出现超类是否参与、细类到超类的完整映射也没有在主文给出。
>
> 按“先合并概率”的理解，SBE 只要求 cat 与 dog 的概率总量落在 animal 区域，不会单独告诉模型该处到底是 cat 还是 dog。梯度可经聚合后的预测传回 decoder 的相关细类分支，但超类约束不能承担同一超类内部的细分类监督。谁是 cat、谁是 dog，仍需要 $\mathcal L_{seg}$ 提供的目标类伪标签来约束。这个解释揭示了 SBE 的能力边界，同时也避免把它夸大成修复所有类别边界的机制。

### 3.4. 训练目标

如图 2 所示，我们的框架包含两个训练目标：分割损失 $\mathcal{L}_{seg}$ 与边界增强损失 $\mathcal{L}_{b}$。二者都为最终分割预测提供有效监督。我们框架的整体训练目标定义如下：

$$
\mathcal{L}=\mathcal{L}_{seg}+\lambda_{1}\mathcal{L}_{b}.
\tag{10}
$$

其中，$\lambda_{1}$ 为权重因子。

> [!note] 我的理解｜两个损失训练同一个预测器，但各自的监督来源不同
> $\mathcal L_{seg}$ 使用 CDA 细化目标类 CAM 后得到的伪标签，负责学习目标类别与像素位置的对应；$\mathcal L_b$ 使用超类原型 CAM 派生的标签，只在选中的样本上额外约束跨超类区域。总目标 $\mathcal L=\mathcal L_{seg}+\lambda_1\mathcal L_b$ 将二者加在同一个 decoder 预测上，实验取 $\lambda_1=0.6$。这不是两个分割网络互相教，也不是先把 DINO 训练好再蒸馏 CLIP 的流程。
>
> 一个数值例子：若某个符合条件的样本 $\mathcal L_{seg}=0.8$、$\mathcal L_b=0.3$，总损失为 $0.8+0.6\times0.3=0.98$；若只有一个超类，按式 (9) 边界损失为 0，这个样本仍然用 $\mathcal L_{seg}$ 学习，并不会从训练中被删除。批次里只有部分样本满足条件时，辅助项如何按有效样本数还是整个批次平均，正文未交代。
>
> 谁在学习可以概括为：**冻结的 CLIP/DINO 生成特征和监督依据，可训练 decoder 接受两类监督。** 图中的 Grad-CAM 梯度用于计算类别热图，应与更新模型参数的训练梯度分开理解。论文没有给出完整的自动微分图、伪标签 `detach` 位置或每个中间张量是否保留计算图，因此可以确认编码器参数冻结，但不能凭框架图逐行声称所有分支的梯度行为。
>
> 此外，主文只命名了 segmentation loss $\mathcal L_{seg}$，没有单独给出其交叉熵公式、忽略像素规则或背景权重。把它理解为“用目标类伪标签监督分割”是正文支持的；把具体损失类型与全部实现参数写死则超出了本文已给信息。$\lambda_1$ 控制的是辅助目标相对主目标的权重，不是对 CDA 与 DINO 的特征做 0.6/0.4 融合。

## 4. 实验

### 4.1. 实验设置

**数据集与评估指标。** 遵循常见的图像级 WSSS 做法 [55]，我们在 PASCAL VOC 2012 和 MS COCO 2014 两个基准上评估了框架。PASCAL VOC 2012 数据集包含 21 个类别，使用 SBD [12] 扩充后，包括 10,582 张训练图像、1,449 张验证图像和 1,456 张测试图像。MS COCO 2014 数据集包含 81 个类别，其中训练图像为 82,081 张，验证图像为 40,137 张。我们使用平均交并比（mIoU）作为主要评估指标。

**实现细节。** 我们采用具有 ViT-Base-16 架构 [10] 的冻结 CLIP 作为视觉编码器，并采用冻结的 DINOv2-ViT-Base-14 架构 [57] 作为 DINO 编码器。对于解码器，我们使用 WeCLIP 中设计的轻量级 Transformer 架构。训练期间，我们使用具有默认参数的 AdamW [28] 优化整个网络。对于视觉编码器，所有图像均裁剪为 $320\times320$；对于 DINO 编码器，则裁剪为 $308\times308$。权重因子 $\lambda_{1}$ 设为 0.6。对于 PASCAL VOC 2012 数据集，我们将批量大小设为 4，最大迭代次数设为 30,000。为 PASCAL VOC 2012 设计的超类集合 $\mathbf{D}_{s}$ 为 {动物、交通工具、家居物品、家具、人}。对于 MS COCO 2014 数据集，批量大小为 8，最大迭代次数为 80,000。COCO 超类集合的详细信息列于附录中。两个数据集的学习率均为 2e-5，权重衰减为 0.01。在推理阶段，我们使用额外的 Dense CRF 后处理 [5]，并采用多尺度因子 {1.0, 1.5}。

## 5. 结论

在本文中，我们发现，不同类别上的类别分布所包含的语义信息比目标类别的激活更有价值。为了充分利用这一点，我们提出 CD-CLIP 方法，其中包含类别分布感知（CDA）模块，通过纳入类别分布关系来细化 CAM。为了抵消 CDA 模块可能引起的过度激活效应，我们还引入超类边界探索（SBE）模块。该 SBE 模块利用 DINO 特征知识，为超类边界区域提供准确监督。在不同数据集上的实验结果验证了 CD-CLIP 中所提出的两个模块的有效性。在未来工作中，我们计划探索用于 CAM 细化的关系，并研究其他骨干网络的益处。
