# 标签规范

标签描述笔记实际讨论的领域、任务、监督设定、模型或可复用操作。目录提供主位置，标签提供交叉入口；按正文和可靠来源选择，不因文件名中出现某个词就自动添加。

## 格式与使用

- YAML 中使用平铺列表：`tags: [semantic-segmentation, clip, retrieval]`；也可逐行写 `- tag`。不使用嵌套层级或带 `#` 的值。
- 全部为英文小写，词组用连字符；保留 `wsss`、`tfs`、`vit`、`cam` 等专用缩写。同一标签只写一次。
- `cv`、`nlp` 是可选领域标签；纯数学、通用算子或跨方向笔记不必强加领域。
- 标签、`type` 和 `status` 分工不同。Hub 可用 `hub` / `moc`，研究算子可用 `research-operator`；不要用标签代替类型或整理状态。
- 模型名、`model`、`aliases`、标题和文献事实保持其原有大小写。年份放文献属性，不新建年份标签。

## 常用标签与语义条件

| 类别 | 现行标签 | 使用条件 |
|---|---|---|
| 领域与基础 | `cv`、`nlp`、`math`、`statistics`、`machine-learning`、`deep-learning`、`linear-algebra`、`optimization` | 内容实际属于该领域或讨论相应基础 |
| 图像任务 | `image-classification`、`object-detection`、`image-processing`、`dense-prediction`、`monocular-depth-estimation` | 正文明确讨论该任务，不由模型名称代推任务 |
| 分割任务 | `segmentation`、`image-segmentation`、`semantic-segmentation`、`instance-segmentation`、`panoptic-segmentation`、`entity-segmentation`、`interactive-segmentation`、`promptable-segmentation`、`referring-segmentation`、`reasoning-segmentation` | 按实际输出和任务定义选择；不同分割任务各自保留，不自动互换 |
| 开放世界与泛化 | `open-world`、`open-vocabulary`、`open-vocabulary-segmentation`、`zero-shot`、`meta-learning` | 有对应任务设定证据；开放词汇分割使用其具体任务标签，零样本另按是否满足未见类别/无目标示例设定判断 |
| 监督与学习 | `supervised-learning`、`fully-supervised`、`weakly-supervised`、`semi-supervised`、`self-supervised`、`unsupervised-learning`、`contrastive-learning`、`representation-learning` | 区分一般监督学习与全监督设定；区分自监督目标与无监督学习，不把术语当作完全等价 |
| 弱监督分割 | `weakly-supervised-segmentation`、`wsss` | 前者指弱监督分割内容；`wsss` 专指弱监督语义分割主题，需有语义分割与弱监督依据 |
| 免训练 | `training-free`、`tfs`、`frozen-backbone` | `training-free` 指目标方法无需额外训练/微调；`tfs` 专指免训练分割；冻结骨干只说明该组件状态，不能单凭冻结添加免训练标签 |
| 基础模型与架构 | `foundation-model`、`transformer`、`vit`、`cnn`、`encoder-decoder`、`backbone`、`resnet`、`unet`、`clip`、`sam`、`dinov2`、`dinov3`、`dino` | 模型/结构是主要讨论对象或关键依赖；分别保留具体模型和通用架构的语义 |
| 具体方法 | `fcn`、`deeplabv3plus`、`segformer`、`setr`、`upernet`、`maskformer`、`mask2former`、`convnext`、`moduseg`、`reme` | 对应方法本身或实质性分析；新方法缩写按来源确认后使用 |
| 注意力与表示 | `attention`、`self-attention`、`multi-head-attention`、`cam`、`affinity`、`feature-extraction`、`pooling`、`prototype`、`prototype-learning`、`prototype-based-segmentation` | 按所解释的机制或操作添加；原型对象、学习过程和具体分割设定可分别标记 |
| 融合、检索与伪标签 | `fusion`、`multi-scale`、`cross-modal-alignment`、`retrieval`、`memory-bank`、`cache`、`mask-refinement`、`pseudo-label`、`pseudo-labeling`、`optimal-transport` | 内容确实解释或使用相应操作；对象标签和过程标签可有不同用途，保留差异 |
| 适配与训练机制 | `foundation-model-adaptation`、`fine-tuning`、`adapter`、`prompt-engineering`、`knowledge-distillation`、`teacher-student`、`regularization`、`loss-function` | 有对应适配、训练、损失或更新机制依据 |
| 多模态与生成 | `multimodal`、`vision-language`、`vlm`、`generative-model`、`diffusion-model`、`stable-diffusion`、`text-to-image`、`vae`、`gan` | 按内容涉及的模态、生成任务和具体模型选用 |
| NLP 与序列 | `language-model`、`seq2seq`、`rnn`、`word-embedding`、`text-embedding`、`tokenizer`、`machine-translation` | 实际讨论语言、序列机制或任务 |
| 工具与数据集 | `pytorch`、`mmsegmentation`、`mmpretrain`、`torchserve`、`python`、`numpy`、`linux`、`pascal-voc`、`voc2012`、`ade20k`、`cityscapes` | 工具或数据集对内容有实质作用；年份型名称属于数据集专名时可以保留 |
| 内容用途与索引 | `research-operator`、`hub`、`moc`、`knowledge-base`、`areas`、`projects`、`survey`、`tutorial`、`guide`、`code-note`、`code-analysis`、`experiment-note` | 为对应内容或导航提供检索；已有教程和代码记录保留自己的用途标签，不因此强制补卡片 |

## 需要分别判断的标签

- WSSS 论文常用 `semantic-segmentation`、`weakly-supervised`、`wsss`；`weakly-supervised` 还可用于其他任务，不能自动得到 `wsss`。`weakly-supervised-segmentation` 保留自身用途，也不自动与 `wsss` 合并。
- 免训练分割可同时用 `tfs` 和 `training-free`，但一般免训练方法不自动加 `tfs`。预训练模型的存在不妨碍目标方法为免训练；反过来，使用 SAM、CLIP 或冻结某个模型也不足以证明整套方法免训练。
- `zero-shot` 与 `open-vocabulary` 分别描述评估/泛化设定和词汇能力，不能互相代替。`open-vocabulary-segmentation` 仍保留分割任务的特指意义。
- `supervised-learning` 描述监督学习范式；`fully-supervised` 描述充分标注的监督设定，二者分别保留。各类分割标签也分别保留。
- 不确定缩写含义时先查正文和来源，不展开猜测；`ssl` 等有歧义词不能仅凭缩写分类。确认自监督语境时使用 `self-supervised`。

## 新增标签

先搜索同义现行标签和相关 Hub。已有标签能准确表达时直接复用；只有形成独立语义、能帮助后续检索时才新增。新缩写需要有明确来源，词组按英文小写与连字符书写。上表覆盖常用类别，未列出的合法专用模型、算法、数据集和操作标签可以继续使用；不要为了缩短列表合并含义不同的标签。

增加标签时同时检查证据、拼写、重复和适用范围。缺乏证据的分类暂不添加，不通过改写正文来凑标签。
